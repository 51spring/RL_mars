# 기존 규칙을 기본으로 둔 PPO 예비 비교

2026-11-09 한국 시간. 앞선 PPO의 결정론적 평가에서 관수 선택이 0이었던 문제를 검토했다. 이번 정책의 기본 행동은 당일 관측에 대한 기존 규칙이다. PPO는 허용된 다른 투입량으로 바꿀 수 있으며, 명시적으로 0 투입도 선택할 수 있다. 규칙과 같은 투입량을 고르는 중복 선택지는 제외했다. 관수 정책은 물만 바꿀 수 있고 공동 정책은 물과 질소를 바꿀 수 있다.

## 현장 재현과 강화학습 정책 평가

| 평가 | 비교 대상 | 해석 범위 |
| --- | --- | --- |
| 현장 재현 평가 | 별도 연도나 포장의 실측 수량·생육·토양 수분과 같은 조건의 DSSAT 출력 | 현장에서 관측한 작물과 관리 반응을 모형이 어느 정도 재현하는지 평가한다. |
| 강화학습 정책 평가 | 공통 시뮬레이션 시즌의 고정 관수·시비 규칙, 관수 PPO와 고정 시비, 관수·시비 공동 PPO | 시험한 DSSAT 조건에서 각 정책의 순수익과 자원 사용을 비교한다. |

gym-DSSAT 옥수수 연구는 무투입·전문가 규칙·PPO를 학습과 정책 선택에 쓰지 않은 기상의 시험 에피소드 1,000개에서 비교했다. 후속 관수·시비 연구는 두 투입의 공동 최적화와, 한쪽만 학습하고 다른 쪽에는 기준 규칙을 적용하는 정책을 비교했다. [gym-DSSAT 평가 방법](https://rgautron.gitlabpages.inria.fr/gym-dssat-docs/Baselines/maize_baseline.html) · [관수·시비 공동 최적화 연구](https://www.ijcai.org/proceedings/2023/0691.pdf)

최종 정책 비교에서는 학습 시즌과 정책 선택용 검증 시즌을 분리한다. 정책과 기준 규칙을 고정한 뒤, 두 과정에 쓰지 않은 공통 시험 시즌에서 같은 기상·초기 토양·자원 제약과 단가를 적용한다. 주 지표는 같은 시즌에서 계산한 **PPO 순수익 − 고정 규칙 순수익**이다. 곡실 매출에서 투입비를 뺀 순수익으로 집계하고, 수량·물·질소 사용량·실패율·제약 위반을 함께 제시한다.

이 보고서의 순수익 결과는 검증 시즌 32–47의 예비 비교에서 얻었다. 두 PPO가 기존 규칙과 같은 행동을 선택했으므로 이 조건에서 추가 순수익은 0이었다. 현장 적용성의 판단에는 별도의 실측 비교가 필요하다.
