## 원본 필드로 설명되는 실패

원본은 BIOMAS에 EARWT×PLTPOP를 사용하지만 PODWT와 YIELD/GNUP에는 EARS를 사용합니다. HRes_Ceres는 다시 GRNWT×PLTPOP를 사용합니다. 따라서 두 기준이 달라지는 조건에서 곡실뿐 아니라 이삭 건물중도 불일치합니다. MZ_PHENOL에는 EARS를 PLTPOP보다 작게 계산하는 분기가 있습니다. 이번 결과의 비율은 저장된 곡실 건물중/N에서 추론했으며 EARS 자체를 직접 계측한 것은 아닙니다.

한 무투입 사례에서는 후보의 실제 반출 경계 잔차가 건물중−13.88184kg/ha, N−0.070938kg N/ha였습니다. 전체 실패 조건의 최대 절대 잔차는 건물중29.85102kg/ha, N0.155894kg N/ha입니다. 단순 낙엽 N 중복 제거로 이 차이를 해결했다고 볼 수 없습니다.

gf=곡실 수확률, sf=줄기 수확률일 때, 저장된 독립 필드로 다음 차이를 재구성했습니다.

```
건물중 잔차 = (줄기DM + PODWT_DM − canopyDM) × (1−sf)
            + (실제 잠재 곡실DM − PLTPOP 기준 곡실DM) × (gf−sf)
후보 N 잔차 = (줄기N + 곡실N − canopyN) × (1−sf)
            + 실제 곡실 반출N − PLTPOP 기준 곡실N × gf
원본 N 잔차 = 후보 기준식 + 누적 낙엽N × (1−sf)
```

원본/후보128개 출력에서 위 식이 binary32 합산 오차 범위 안에서 잔차를 설명했습니다. 오차 맞춤용 계수를 추정하지 않았습니다. 원인 설명과 물리 보존을 구분합니다.
