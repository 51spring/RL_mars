# 입력 메타데이터 수정과 수확 경계 감사

2026-11-06. 원본 vendor 소스와 기존 CPU/CUDA 이미지는 유지했습니다. 수정·수확 진단 바이너리는 별도 `mars-dssat:metadata-audit` 이미지로 검증했습니다.

## 메타데이터 오류와 수정 범위

- `IPFLD`에서 정상 읽기의 IOSTAT=0을 오류로 처리하던 세 조건을 수정했습니다. 좌표 판정이 표고 읽기의 마지막 IOSTAT에 의존하지 않도록 했고, 결측 문자열/수치의 초기값을 명시했습니다.
- `ModuleData`에 빠져 있던 FIELD 문자형 저장·조회(CYCRD/CXCRD/CELEV)를 추가했습니다. 기존 GET/PUT 호출과 Summary.OUT 형식은 유지합니다.
- 원본 UFGA8201 템플릿의 X/Y 값은 29.6380/-82.3689입니다. 보정 프로필은 이 특정 필드에 대해 경도 X=-82.3689, 위도 Y=29.6380, 표고40m를 명시합니다. 다른 지점의 좌표를 자동으로 뒤집지 않습니다. 기상 관측소 값과 필드 표고를 같게 만들지 않습니다.
- SSKS=-99는 명시된 결측값으로 유지하고 '0 전도도' 경고 집계에서 제외합니다. 실제 0·근접0·잘못된 음수는 계속 집계합니다. 토양층 값·추정식·물성값은 바꾸지 않았습니다.

## 수확 경계에서 실제 확인한 것

네이티브 HRes_Ceres 호출 직후, 고사물 초기화 직전에 읽기 전용 PDI 이벤트를 추가했습니다. 기존 생육 방정식·수확 계산·잔사 대입은 변경하지 않았습니다. 진단 사용/미사용의 두 무피해/피해 쌍(4시즌)도 기존 상태 궤적이 정확히 일치했습니다.

| 곡실 N (kg N/ha) | 81.2191 | 81.5775 |

현재 실행은 **RNMODE=C**입니다. 소스는 Q/F 연속·휴경 모드에서만 수확 잔사를 계산하며 C 모드에서는 잔사 구조체를0으로 둡니다. 곡실량은 Summary 수확량의 출력 반올림 오차0.5kg/ha 이내에서 일치했지만 작물의 곡실/지상부 재고는 수확 후에도 남아 있습니다.

따라서 경제적 수확 매출과 물리적 재고 반출을 같은 것으로 취급하지 않습니다. 기존 성숙 직전 N 재고 검사에 곡실 반출을 다시 더하면 이중 계산이 됩니다. **이번 결과로 수확 후/다음 시즌 수지나 전체 원소 탄소 게이트를 켜지 않습니다.**

고사엽은 식물체에서 누적됐다가 SEASEND에 SENESCE로 전달됩니다. Q/F 연결을 구현할 때는 이 전달의 단위와 다음 시즌 토양 유입 시점까지 검증해야 합니다. 단일 시즌 C 모드의0 잔사를 오류로 간주해 임의 잔사나 탄소 비율을 추가하지 않았습니다. 표의 수량 차이는 기술 진단일 뿐 보정된 방제/회복 효과로 해석하지 않습니다.

## 기본 학습 프로필에 반영

새 실행 이미지는 `mars-dssat:ppo-cpu-metadata`, `mars-dssat:ppo-cuda-metadata`입니다. 기존 학습 패키지 위에 검증된 메타데이터 바이너리만 추가하며 라이브러리와 작물 파라미터는 그대로 둡니다. 이미지의 런타임 변수로 기본/잎 피해 백엔드와 UFGA 좌표 보정을 선택하고, 이 변수와 이미지 ID를 실행 manifest에 저장합니다.

`benchmark_real_ppo.ps1`와 `smoke_real_ppo.ps1`는 새 프로필이 기본입니다. 원본 재현은 `-LegacyMetadata`로 선택합니다. 모든 새 실행은 고유 outputs/runs 폴더를 사용합니다.

```powershell
./scripts/verify_metadata_harvest.ps1
docker build -f docker/Dockerfile.ppo-metadata -t mars-dssat:ppo-cpu-metadata .
docker build --build-arg LEARNER_IMAGE=mars-dssat:ppo-cuda -f docker/Dockerfile.ppo-metadata -t mars-dssat:ppo-cuda-metadata .
./scripts/benchmark_real_ppo.ps1 -Device cpu -Mode no_pest -Steps 1024
./scripts/benchmark_real_ppo.ps1 -Device cpu -Mode experimental_pest -Steps 1024
./scripts/benchmark_real_ppo.ps1 -Device cuda -Mode experimental_pest -Steps 1024
```

세 연결 검사 모두 1,024단계·8업데이트·완료4시즌·재로딩·raw 평가·원장·프로세스 정리를 통과했습니다. 보정 이미지의 기본 DssatBackend/LeafDiagnosticBackend를 직접 실행해 올바른 최종 좌표와 동일한4707kg/ha 수량도 확인했습니다. 새로운 소프트웨어 검사는86개 통과했습니다.

추가 검증 없이 이번 프로필에 과거 CPU/CUDA 102,400단계 장기 통과 실적을 그대로 부여하지 않습니다. 프로필별 검증 근거와 당시 설정/소스를 분리합니다. 연구용 해충 제한 및 농학 검증 미완료 상태를 유지합니다.
