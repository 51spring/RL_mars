## 현장 재현을 다시 검토할 조건

1. **기상·관리.** 현장 우량계와 일별 집계 경로로 강수 차이를 대조하고, 포장별 파종과 실제 시비·관수 이벤트, 관개수 N의 공급원·농도를 연결한다.
2. **토양·초기 상태.** 구역·블록의 역사적 코어를 실제 포장과 수리층에 연결하고, 날짜가 있는 파종 초기 수분·질산태·암모늄태 N 값을 확보한다.
3. **품종·독립성.** DK 52-04 VT3/RIB와 모형 논문의 DCK52-59 표기 관계 및 DSSAT 4.8 계수 출처를 확인한다. 같은 시험의 2012·2013년 완전·최저 관수 처리에 RZWQM2 선행 보정 노출이 있으므로 독립 검증을 연구 단위로 구분한다.
4. **판정 범위.** 관측 단위·날짜 창·결측·수치 허용범위를 사전에 정한다. 피해·회복 검증에는 별도 적엽 또는 실제 피해의 투입량과 전후 관측이 필요하다.

활성 연구 레지스트리와 우선순위 파일의 해시는 최근 진입 점검과 일치했다. 등록 연구 10개와 당시 점검 시나리오 28개의 기준을 유지했고, LIRF 2012–2013의 활성 등록 승격은 0건이다. 정량 준비 연구는 0개이며 `research_ready`와 `main_training_allowed`는 모두 false다.
