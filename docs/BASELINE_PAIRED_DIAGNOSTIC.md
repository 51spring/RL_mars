- 무해충 환경, 보정된 메타데이터 CPU 이미지 `mars-dssat:ppo-cpu-metadata`를 사용합니다. v2 수확 계약 후보의 검증으로 해석하지 않습니다.
- 고정 규칙 정책은 수분 스트레스0.3 이상에서10mm 관수를 요청합니다. 질소는 제안서 일정40/45/80DAP에27/35/54kg/ha를 요청하며, 공통 마스크에 맞는 행동으로 제한됩니다. 현재 값은 미튜닝 진단 설정입니다.
- `NoInputPolicy`는 같은315차원 관측과17개 마스크를 받아 관수·시비·방제0을 선택합니다. 관측에 없는 시즌 정보는 정책에 전달하지 않습니다.
- validation 주소0부터 기본4개 시즌만 사용합니다. 동일 주소의 날씨/예산 배율/감축 조건을 두 정책에 공유하며 최종 test split은 사용하지 않습니다.
- 감축 발생 시점은 정책이 바꾼 생육단계에 따라 달라질 수 있습니다. 숨겨진 시나리오를 정책에 제공하거나 공지를 임의로 동기화하지 않습니다.

## 독립 확인

일별로 행동의 마스크 적합성과 물·질소·방제 제품비/노동비를 확인합니다. 일별 보상 합계, 독립 비용 합계, 수확 수익, 최종 net return을 대조합니다. 물·질소·살포 횟수도 행동 합계와 종료 결과를 비교합니다. 원장 검증은 공통 환경의 같은 자원 제약을 통과해야 합니다.

