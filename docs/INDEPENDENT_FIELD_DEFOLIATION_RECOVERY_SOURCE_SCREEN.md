## LeafScan 실제 파일 대조

공식 파일 목록의 Git blob 해시와 크기로 메타데이터 3개를 검증했다. 포장·식물·잎의 계층 키가 연결된다. README는 7개 포장과 149개 잎을 설명하나, 이번에 확보한 메타데이터에는 **6개 포장·18개 식물·150개 잎 레코드**가 있었다. README와 파일의 차이는 확인 범위에 남겼다. 

- 자연 피해 표기 22개는 모두 손실률 필드가 비어 있다. 원본 면적 필드가 있더라도 손실 전 온전한 잎 면적이라는 근거는 확인되지 않았다.
- 모의 피해 표기 115개 중 **94개**에서 원본·모의 면적 필드가 모두 유한 수치였다. 이 값의 단위와 생성 방식, 독립 반복 판독의 존재를 확인해야 한다. 미디어 전체는 이번 선별에서 내려받지 않았고 메타데이터와 저장소 목록을 보존했다. [Zenodo 등록 자료](https://doi.org/10.5281/zenodo.17289901)
