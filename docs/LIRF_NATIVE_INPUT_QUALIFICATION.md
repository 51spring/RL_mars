## 기상 헤더 오류와 호환 조정

writer는7자리 YYYYDDD 값을 출력했지만 헤더의DATE 필드 끝은5열이었다. native의 `Weather/IPWTH_alt.for`는 날짜를7자리로 읽으면서, 각 기상 변수는 헤더에서 얻은 열 범위로 읽는다. 원본 헤더에서는 일사량에 날짜 끝 일부가 섞였다. 예를 들어2008-01-01의입력9.35가native에서1.0으로 읽혔다.

호환 어댑터는 첫7문자의 `@DATE  `를 `@  DATE`로만 바꾼다. SRAD와 이후 헤더의 끝 위치·모든 수치 행·날짜는 유지한다. 다른 레이아웃이나5자리 날짜·중복 적용은 거부한다. 원본 writer 파일을 덮어쓰지 않았다.
