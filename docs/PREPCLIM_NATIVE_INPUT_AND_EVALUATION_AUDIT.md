## 네이티브 입력 연결

별도 모델링 배포본에서 DSSAT 4.8.0.15용 실험 파일과 참조 항목을 확인했다.

| 항목 | 확인 내용 |
| --- | --- |
| 실험 | FIFU9901.MZX. 파종 시기 4수준×질소 시나리오 3수준의 처리 정의 12개 |
| 품종과 생태형 | MZCER048.CUL의 PIO 3475 계열 IB0031이 MZCER048.ECO의 IB0001을 참조 |
| 토양과 초기값 | SOIL.SOL에 Fundulea 토양 FIFU960007이 있으며 MZX에 7개 깊이의 초기 수분·NH4·NO3 값이 설정됨 |
| 기상 | MZX의 RCP8 참조와 배포 스크립트의 시나리오별 기상 코드 치환 확인 |
| 실행 구성 | Linux ELF 실행 파일과 연도·시비량·파종일 치환용 스크립트가 있다. 배치 파일은 0바이트다. |

배포 스크립트의 보조 템플릿에는 0·23·46 kg N/ha가 들어 있지만, 스냅숏 MZX는 세 수준 모두 0이다. 처리명에서 시비량을 복원하면 잘못된 실행이 된다. 스냅숏에는 여러 연도의 날짜와 Iowa 시험 설명이 남아 있어 Fundulea 실측의 계보로 사용할 수 없다. 재실행에는 한 시나리오·연도에 대해 템플릿 치환 결과와 실행 경로를 고정하는 단계가 필요하다. 이 환경에서는 Docker Linux 엔진에 연결되지 않았고 WSL 조회가 접근 거부를 반환해 실제 실행은 확인하지 못했다. [모델링 배포본](https://doi.org/10.5281/zenodo.13132588)

## 활용 판정

v2 출력 예시에는 모의 수량·작물 N 흡수·용탈 등의 열이 있다. 배포본의 summary.csv도 모의 실행 결과다. 공개 패키지에서 독립 시험구별 수량·질소 관측 및 보정·평가 역할을 뒷받침할 식별자를 확인하지 못했다. 이 예제는 외부 실행 기술 검사용 후보로 분류했다. 독립 현장 평가에는 등록하지 않았다.
