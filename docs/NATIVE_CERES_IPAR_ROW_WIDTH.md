# CERES 무피해 이랑 폭 민감도

UFGA의 무피해 조건을 재사용해 FileX의 PLRS만 38cm와 76cm로 바꾸는 실행 스크립트를 준비했다. 보관 FileX에서 폭 필드의 교체와 원복을 검사했다. 실제 실행은 같은 시드·품종·밀도·기상·관수·시비를 사용하고, 공통 성장일의 차단율 차이를 폭 성분과 LAI 성분으로 나눈다. 분해는 폭과 LAI를 바꾸는 두 순서에서 얻은 차이를 평균한다. [실행 스크립트](../scripts/verify_ceres_ipar_row_width.py)

## 실제 DSSAT 실행

Docker Linux 엔진 응답을 확인하고, 앞서 사용한 진단 이미지와 동일한 이미지 ID로 두 시즌을 수확까지 실행했다. UFGA8201, 시드 123456, 입모밀도 7.2개/m², 관수 80mm, 질소 116kg/ha를 적용했다. FileX의 PLRS만 달랐고 공통 162일의 강수·일사·최저·최고기온이 일치했다. 두 실행의 성장일 124개가 모두 연결됐으며 수확일도 일치했다. [실행 매니페스트](../outputs/runs/20261107T102705Z_native_ceres_ipar_row_width_d7935f89/manifest.json)

| 공통 성장일 평균 LAI | 1.1723 | 1.1684 | +0.0039 |
| 최고 LAI | 2.1136 | 2.1056 | +0.0080 |
| 곡실 수확량 (kg/ha) | 4,953 | 4,607 | +346 |

124일의 평균 광 차단율 차이는 **+5.023%p**였다. 이 중 이랑 폭을 바꾸고 LAI를 고정한 직접 성분은 **+4.938%p**, 두 실행의 LAI 경로 차이 성분은 **+0.085%p**였다. 각 성장일에서 폭과 LAI를 바꾸는 두 순서의 기여를 평균했고 합계가 전체 차이와 일치했다. LAI 성분은 일별로 −1.473~+1.107%p였다. 광 차단율을 네이티브 차단 에너지·입사 PAR·밀도로 별도 재계산했고 FileX 해시도 대조했다. 소프트웨어 검사 204개가 통과했다. ## 보관 기록을 사용한 고정 LAI 계산

엔진을 시작하지 못했던 앞선 점검에서는 61cm 무피해 성장 기록의 LAI·입사 PAR·밀도를 124일간 고정하고 이랑 폭의 직접 항만 바꿨다. 38cm−76cm 차단율은 평균 +4.94%p, 최대 +6.29%p였다. [고정 LAI 진단 결과](../outputs/runs/20261107T102234Z_ceres_ipar_width_archive_ff3d4b4f/verification.json)

이번 수확량 차이는 한 개의 UFGA 기상 시드에서 얻은 모형 결과다. 다음은 38·76cm 대비와 관리 조건을 고정하고 복수의 공통 기상 시드에서 반응 범위를 확인하는 기술 검사다. Battaglia 현장 검증과 본 학습은 보류 중이다.
