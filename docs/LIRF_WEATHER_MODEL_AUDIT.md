# LIRF 기상 원관측과 공개 모형 패키지 감사

2026-11-06. 기존 원본·파생자료는 유지하고 새 진단 폴더에 출처와 비교 결과를 저장했다. 계수 추정·DSSAT 실행·결측값 자동 적용은 하지 않았다.

## 공개 모형 패키지

[USDA 원배포](https://agdatacommons.nal.usda.gov/articles/dataset/USDA_ARS_Maize_Modelling_Dataset_Greeley_Colorado/24660264)의 Figshare API가 지정한 `agmip_download.zip`을 확보했다. DOI `10.15482/USDA.ADC/1212385`. 이것은 기존 LIRF2008–2011 현장 연구의 보조 패키지이며 새 독립 연구로 세지 않는다.

ZIP의5개 파일과 중첩 cultivar ZIP을 해석했다. ACE/DOME 파일은 gzip JSON이다. 내용은 **2008년100ET 한 처리**, 토양1프로필, 기상1관측소/366일, 생육·수량 시계열16행에 한정된다. 전체4년×6처리의 입력으로 확장할 근거는 없다.

품종 파일은 `MZCER045.CUL`, `IB1068 DEKALB 521`이다. 현장 원본의 DeKalb52-59와 이름이 다르다. 공개 계수가 존재한다는 사실과 현장 품종과의 동등성·DSSAT048 호환성·독립 보정 여부는 구분한다.6개 알려진 계수 뒤 추가 숫자도 있어 자동으로 열을 버리거나048 파일에 이식하지 않는다. 계수 추정에 이 현장 수량이 쓰였는지 확인 전 독립 검증에 무조건 사용하지 않는다.

초기 수분/N 프로필과 DOME의 채움 규칙도 확보했지만 이를 실측값 또는 모든 처리의 기본값으로 간주하지 않는다. DOME에는 SLDR0.5, SLRO60, SLPF0.95, SALB0.13 및 상대 날짜 채움 등이 있다. 원본 워크북·현장 방법과 일치하는지 추가 대조해야 한다.

## 기상 단위와 날짜

원본 XLSX의 시간별 일사량 단위는 `kJ/m²/min`, 시간표시는 Mountain Standard Time의 **구간 종료 시각**이다. 하루는01시부터 다음 날00시까지24개 관측이다. 일사량 재집계는 `sum(hourly_mean) × 60 / 1000`으로 MJ/m²/day가 된다. [CoAgMET 공식 API](https://coagmet.colostate.edu/data/doc.html)는 일사량을 W/m²로 제공하므로 API 일평균은 `×86400/1e6`으로 변환한다. API는 metric을 명시하고 관측소·QC·MST·중복 날짜를 검사했다. API의 −999를 결측으로 유지했다.

1,461일을 감사했다. 시간 기록이 온전한1,460일 중 일별 값도 존재하는1,457일을 비교했고,292일은 표시 정밀도에 따른 진단 범위0.012200001MJ/m²/day를 초과했다. 최대 차이는6.6618이었다. 이는 농학적 허용오차나 모형 오차가 아니다. 일별 자료는 다른 관측소로 보완된 날도 있으므로 시간별 재집계와의 차이를 일별 값의 오류로 단정하지 않는다.

시간별 원본에는 음의 일사량62개가 있다(최솟값−0.13kJ/m²/min). 산술 감사에서는 부호를 보존하고0으로 잘라내지 않았다. 물리 품질 검증 통과를 의미하지 않는다.2011-12-31은 시간표시가 중복되고 필요한 구간이 빠져,24행이 있어도 집계를 거부했다. 원본 시간표시와 경고를 별도 보존했다.

## 결측4개 재확인

각 결측일 전후3일에 대해 GLY04·KSY01의 공식 QC 일별자료6응답을 보존했다. 같은 관측소의 결측4값은 현재 API에서도 −999다. 시간별 평균기온의 최솟값은 일 최저기온이 아니므로 대체하지 않았다.

| 날짜·항목 | 원자료 관측소 | 같은 관측소 API | 원본 시간별 일사량 재집계 후보 |
|---|---|---|---:|
| 2009-10-02 SRAD | GLY04 | 결측 |18.9888MJ/m²/day |
| 2010-07-16 SRAD | GLY04(정의상 기본값) | 결측 |30.8232MJ/m²/day |
| 2011-08-11 SRAD | KSY01 | 결측 |24.0534MJ/m²/day, 단 시간별 기본 관측소는GLY04 |
| 2011-08-11 TMIN | KSY01 | 결측 |대체하지 않음 |

위 재집계값은 **후보로만 보존했고 적용하지 않았다**. 특히2011년은 일별/시간별 관측소가 다르다. 인접 관측소 수치도 별도 저장했지만 성능을 보고 선택하거나 동일 원관측으로 표시하지 않는다. 원본의4결측 상태는 유지한다.

## 검사·근거·다음 단계

`src/mars_env/lirf_weather.py`는 감사 전용 시간·단위·결측 검사를 제공한다. 기본 정책 기상/관측과 연결하지 않았다. 시간 경계·23시간/중복·결측/비정상 수치·음수 보존·API 단위·관측소·시간대·중복 날짜 검사7개를 추가했다.

- 모형 패키지: `outputs/runs/20261106T084700Z_lirf_model_package_f84234e1/verification.json`
- 공식 관측소: `outputs/runs/20261106T084911Z_lirf_station_windows_0f693d5f/verification.json`
- 감사: `outputs/runs/20261106T085314Z_lirf_weather_model_audit_86776d47/verification.json`

초기 감사가 음수 센서값과 중복 시간표시를 차단한 기록도 보존했다. 음수는 산술 감사에서 보존하도록 명시했고, 중복 시간은 유효 집계로 승격하지 않았다. 기존 기록을 덮어쓰지 않았다.

다음은 **2008년 공개 토양/초기조건/관리 입력과 현장 원자료의 대응**, 품종명·계수 보정 이력 및 단위 확인이다. 전체 연구를 독립 검증 후보로 유지하며 계수 적합에 사용하지 않는다. 이후 기상 대체 프로토콜·외란 포함 기준·비교 허용범위를 사전에 정해야 한다. 농학 검증·본 학습 허용은 계속 false다.
