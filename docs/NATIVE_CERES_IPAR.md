# CERES-Maize 성장 시점 IPAR 진단

성장 루틴에서 광 차단 에너지와 잠재 탄소량을 계산한 직후, 네이티브 날짜와 LAI·재식밀도·이랑 폭·SRAD·입사 PAR·소광계수·IPAR를 읽는다. 이 값은 진단 전용 Docker 이미지에서 JSONL로 기록한다. 네이티브 계산과 정책 상태 스키마에는 진단값을 추가하지 않았다. 일별 IPAR의 단위는 MJ/개체/일이다.

UFGA8201, 시드 123456, 동일한 관수·시비 일정에서 무피해와 파종 후 45일의 75% 잎 피해를 각각 진단 켠 실행과 기준 실행으로 짝지었다. 총 4시즌에서 전체 상태 기록과 수확 결과가 각 쌍에서 정확히 일치했다. 기록 파일의 이미지 ID와 소스 해시는 실행 매니페스트에 있다. [실행 매니페스트](../outputs/runs/20261107T070235Z_native_ceres_ipar_cee567c5/manifest.json)
