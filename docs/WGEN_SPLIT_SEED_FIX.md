# 학습·검증·시험 WGEN 시드 분리

2026-11-10 한국 시간. 이전에는 시즌 주소별로 큰 정수 시드를 생성한 뒤 gym-DSSAT가 그 값을 초기화 시드로 사용해 10001–99998에서 다시 뽑았다. 외생 매니페스트의 서로 다른 시드가 같은 네이티브 WGEN 시드에 연결될 수 있었다. 학습 37,594개와 검증·시험 각 1,000개에서 이 경로를 재현했을 때 검증 334개와 시험 348개가 학습의 실제 WGEN 시드와 겹쳤다.

| 분할 | WGEN 시드 범위 | 고유 시즌 용량 |
| --- | --- | ---: |
| 학습 | 10001–99998 | 89,998 |
| 검증 | 1–4999 | 4,999 |
| 시험 | 5000–9999 | 5,000 |

새 배정은 분할과 루트 시드로 시작점과 구간 크기에 서로소인 간격을 정한다. 같은 설정에서 시즌 주소는 해당 구간의 서로 다른 값에 대응한다. 할당 범위를 모두 쓰면 다음 주소를 거부한다. 해충 유입, 조사 오차, 물 감축 및 예산 난수의 주소와 생성 방식은 기존대로 유지한다. 같은 시즌 주소를 여러 정책·감축 조건에서 재사용하면 같은 날씨를 공유한다. 매니페스트에는 배정 버전과 실제 WGEN 시드를 기록한다.

외생 시즌으로 실행하면 무해충·실험용 해충 환경 모두 배정된 정수를 PDI에 전달한다. Gym이 생성자에서 다시 뽑은 값은 PDI 설정이 작성되기 전에 배정값으로 교체한다. 이 값은 네이티브 IPSIM의 RSEED1을 통해 WGEN에 들어간다. 기존 기술 진단처럼 외생 시즌 없이 숫자 시드만 지정하면 기존 동작을 사용한다.

## 검증

- 전체 분할 범위에서 중복 없는 배정과 용량 초과 거부를 검사했다. 예정된 39,594개 주소의 WGEN 시드는 모두 달랐다.
- 과거 학습 주소 5724와 시험 주소 3은 WGEN 시드 22758을 공유했고, 실제 DSSAT에서 공통 147일의 강우·최저 및 최고 기온·일사량과 건조 곡실 1,113 kg/ha가 일치했다. 수정 후 같은 두 주소의 시드는 98208과 7370이었고, 공통 159일 중 네 날씨 변수가 모두 같은 날은 0일이었다.
- 범위 경계의 시드 1·4999·5000·9999·10001·99998을 실제 PDI 출력에서 확인했다. 무해충 및 실험용 해충 프로세스 경로는 배정 시드로 직접 실행한 결과와 각각 131일 날씨가 모두 일치했다. 관수 행동을 바꾼 두 정책의 공통 기상도 일치했다. [네이티브 검증](../outputs/runs/20261109T223243Z_wgen_split_seeds/verification.json)
- 수정 전에 학습한 체크포인트를 새 배정으로 재개하려는 요청은 시작 전에 거부한다. 수정 전 PPO와 수익 기록은 기술 진단 이력으로 보존한다. 새 배정의 학습·검증 결과를 얻으려면 학습부터 다시 실행해야 한다. 이번 검증에서 최종 정책 평가는 실행하지 않았다.

Docker 시작을 복구하기 위해 오류가 난 소켓만 들어 있던 두 런타임 폴더는 이름을 바꿔 보존한 뒤 엔진을 재시작했다.
