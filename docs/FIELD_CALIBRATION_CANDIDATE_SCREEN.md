## 다른 후보의 보류 이유

Mendeley 두 자료는 원 공개 페이지와 페이지에 포함된 구조화 메타데이터를 확보했다. 비기밀·파일 포함 데이터셋으로 표시되지만 원 HTML의 파일 목록은 loading상태다. 빈 목록을 ‘파일 없음’으로 판정하지 않았다. 실제CSV/XLSX payload는 취득하지 않았으므로 건조 기준·불확실성·전체 입력·보정노출을 미검증으로 둔다.

새 LIRF확장 단서는 기존2008–2011과 겹친다. 이전12파일 조사에서 포장별 수분을 확보하지 못했다는 결론은 당시 확인 파일 범위에 한정되며 새 확장자료의 부재를 뜻하지 않는다. 이번에는 확장자료의 원문/통합 파일과 공식 저장소 URL을 확보하지 못했다. 기존 연구 역할을 바꾸거나 원자료 취득으로 표시하지 않았다.
