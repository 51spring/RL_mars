## 원자료와 요약표

실험단위ID32개는 관측 연도에 걸쳐 같은 처리코드를 유지한다. 논문은4반복 완전임의블록 분할-분할구 설계(주구 관수,분할구 피복작물,재분할구 잔사),연도를 반복측정으로 명시한다. ID숫자를 블록/주구/분할구 번호로 자동 해석하지 않는다. 논문의 계획상4반복×8처리×9년=288칸 중 공개 곡실행은271개다. 2010년16칸과2018년1칸의 값이 없으며 원인은 미확정이다. 모든 그룹을 n4로 채우거나 연도별 행을 독립 연구로 세지 않는다.

공개 요약표의8처리×9년×4목표값=288조합을 원자료 평균/표본SD와 대조했다. 단위는 건물중 kg/ha→Mg/ha(÷1000),N은 kg N/ha 그대로다. 처리 의미를 통해 XLSX의A/N을 논문의M/R과 대응했다.

| 목표값 | 평균 차이 검토 표시 | SD 차이 검토 표시 | n1로 SD 계산 불가 |
|---|---:|---:|---:|
| 곡실 건물중 | 0/72 | 9/71 | 1 |
| 지상부 건물중 | 0/72 | 9/71 | 1 |
| 곡실 N | 1/72 | 9/71 | 1 |
| 지상부 N | 9/72 | 17/71 | 1 |

표시 기준은 산술 검토용 0.000001Mg/ha(0.001kg건물/ha),0.0001kgN/ha이다. 작은 저장/보고 자릿수 차이와 큰 차이를 구분하기 위한 기준이며 계측오차·네이티브 출력 허용오차·모형 적합 합격선이 아니다. 모든 부호 있는 차이와 출처 셀은 `raw_summary_comparisons.json`에 보존했다. 차이가 작은 경우에도 원자료의 완전성·오차 자격을 부여하지 않는다.

곡실 SD 차이는 DCN2011–2018의8건과 FXN2015의1건이다. 예를 들어 DCN2015는 원자료 표본SD2.081301Mg/ha,보고SD0.590534Mg/ha다. 곡실N의FXN2018 평균은 원자료188.809와보고198.96367kgN/ha로 다르다. 지상부N은FCA2011–2018와FXN2018의평균이 다르다. 원자료가 반드시 정답이라고 확정하거나 보고값을 덮어쓰지 않는다. 원자료/요약표의 개정·제외 규칙 또는 다른 집계법인지 확인할 때까지 미해결로 유지한다. SD를 SE나 독립 처리 대비 오차로 변환하지 않는다.

## 강수와 관수

강수13문자열 날짜는 원본 헤더 `Date (DD/MM/YYYY)`에 따라 진단 사본에서만 해석했다.2010-01-01–2018-12-31의3287일은 날짜 중복/공백이 없다. 강수 날짜와 값이 연결된다는 검사이며 일별 최고/최저기온·일사나 전체 기상을 확보했다는 뜻은 아니다. 파싱 방법과 원 셀을 `precipitation_date_candidates.json`에 보존했다.

관수량 숫자가 있는1344행은 날짜·처리·양·방식의336고유조합이 각각4회 반복된 구조다. 포장 반복과 일치할 가능성은 있으나 표에 실험단위ID가 없어 확정하지 않았다. 고유조합별cm→mm(×10)와 출처 셀4개를 진단 후보로 남겼다. 모든 행을 하나의 처리 일정으로 합치면 고유조합 합계의4배가 된다. 반대로 단순 중복 삭제 역시 실제 처리 일정으로 승인하지 않았다.

량 빈값1904행·날짜 빈값32행을0/날짜로 채우지 않았다. 숫자0 관수행은 없다. `irrigation_seasonal_sum_diagnostics.json`의 두 합계는 과다합산 위험을 보여주는 진단이며 네이티브 관수 입력이 아니다. 논문의 deficit=full60%를 빈 관수일 생성 규칙으로 쓰지 않았다.

## 원논문으로 확인한 입력과 남은 공백

17개 출처 명세는 `source_input_dossier.json`에 페이지와 상태를 연결했다. 주요 확인사항은 다음과 같다.

- 수량은0%수분 건물중이다. 부지40.582N/98.144W/552m,표층0–30cm밀도1.25g/cm3·물1:1pH6.8·SOC16.2g/kg가 보고된다. 이 스칼라를 전체 토양층으로 복제하지 않는다.
- UAN32-0-0의200kgN/ha·V4–V6측조 주입을 본문에서 독립 확인했다. 처리코드의200만으로 추정한 값이 아니다. 연도별 정확한 날짜/깊이는 미확보다.

- 토양은2010년10월에0–150cm를7구간 측정하고 모형에는6구간을 사용했다는 설명만 있다. 실제 층별 수치·초기 물/무기N·연도별 옥수수 파종/밀도/관리·품종/유전계수는 현재 취득 파일에서 미확보다. 본문의 토양 수치 `Table 1` 참조는 실제표1(ANOVA p값)과 맞지 않아 자동 교정하지 않았다.
- 기상 관측소HARVARD4SW(~1.5km)는 확인했지만 강수 이외 전체 일별 기상파일은 미취득이다. 기후평균을 일별 자료로 대체하지 않는다.
- RZWQM2는 full/no-cover/stover-retention(FXR,워크북FXN)으로 보정하고 나머지 처리로 평가했다.4반복 평균 입력,수분 관측 기반 수리계수 보정,초기화Wizard·부식1/9/90%,질산화N2O분율0.044가 보고된다. DSSAT 품종계수/관측 초기상태로 전송하지 않는다. 나머지 처리를 별개 독립 연구로 세지 않는다.
