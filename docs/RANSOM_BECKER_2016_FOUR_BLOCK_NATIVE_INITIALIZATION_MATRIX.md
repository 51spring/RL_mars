# Becker 2016 4블록 DSSAT 초기화 비교

2026-11-08 한국 시간. 4블록에 Hubbard·Mosford와 4월 21일 수분 가정 두 가지를 교차해 16조건을 고정했다. 초기 수분은 대표층별 가용수분 50% 또는 33 kPa 배수상한으로 설정했다. 모든 조건에 St. Cloud 기온 평년값, 콩 잔사 500 kg/ha, 코어 유기탄소와 SSURGO 심층 대표값, 미채취 깊이의 무기질소 0.01 mg N/kg을 적용했다. 입력 파일 해시를 네이티브 실행 전에 기록했다. 실행은 격리 이미지의 기술용 품종과 무관수·무시비 조건을 사용했다. ## 네이티브 초기 재고

- 16조건 모두 완료됐다. 두 내부 파일의 시작일과 자동 세분층 168개를 대조했다. 시작 수분은 Hubbard 121.74·185.98 mm, Mosford 153.66·217.59 mm였다. 가용수분 50% 후보 명세와의 차이는 FileX 층별 체적수분의 소수 셋째 자리 출력으로 설명됐다. Mosford의 해당 후보는 명세의 153.03 mm에서 153.66 mm로 바뀌었다.
- `DSSAT48.INP`의 질소 농도로 초기 재고를 다시 계산했으며, 16조건 모두 상세 질소 장부와 허용오차 0.00055 kg N/ha 안에서 일치했다. 원래 FileX 농도와 비교하면 INP 반올림이 재고를 최대 0.00456 kg N/ha 바꿨다. 이 차이는 별도 기록했다.
- 두 대표층 모두 4월 21–26일 강수 39.2 mm를 재현했다. 상세 네이티브 무기질소 장부의 파종 전 누적 잔차는 출력 자릿수에서 0.0000 kg N/ha였다. 26일까지의 모의 순무기화 범위는 2.89–17.79 kg N/ha였다. [검산 결과](../outputs/runs/20261108T092659Z_ransom_becker_2016_four_block_native_initialization_matrix_dc08e77e/verification.json)

## 4월 26일 수분 코어 대조

모든 블록에서 용적밀도를 실측한 공통 구간인 0–23 cm의 수분 저장량을 비교했다. 코어 채취 시각이 기록되지 않아 25일 종료와 26일 종료를 각각 사용했다.

블록별 전층 비교는 보고서에 따로 기록했다. 용적밀도 결측층은 Saxton 추정값으로 환산한 조건부 비교에만 포함했다. 코어 오차로 토양이나 초기 수분을 선택하지 않았다. 이번 결과는 입력 전달과 모의 수분의 기술 대조이며 농학 정량 등록은 0건이다.
