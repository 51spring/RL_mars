## 입력 경고의 원인

원본 `InputModule/ipexp.for`는 좌표·표고 숫자 읽기의 `IOSTAT == 0` 성공 조건에서 오류 경고를 내고 결측값으로 바꾸는 분기를 포함합니다. FIELD 전송에서도 문자 좌표를 전달한 뒤 Integer 전송 경고가 나타납니다. FileX의 좌표 행은 29.6380/-82.3689/40이며, 기상 파일 UFGA8201.WTH의 관측소 행은 29.630/-82.370/10입니다. 원본 필드의 X/Y 순서 및 실제 모듈별 좌표 사용은 별도 수정·검증 대상입니다.

토양 IBMZ910014의 8층 SSKS는 모두 -99입니다. `IPSOIL_Inp.for`의 `< 1e-4` 분기가 음수 결측값에도 적용되어 'zero conductivity' 경고를 냅니다. SLPF=0.92도 원본 토양 입력입니다. 경고 제거를 위해 물성값을 임의 추정하거나 좌표를 바꾸지 않았습니다. 원본 입력·WARNING.OUT을 보존했고, 수정할 경우 별도 이미지와 동일 조건 회귀를 요구합니다.

실험용 해충의 성숙 시점에는 토양 유기/무기 N과 식물체·피해 반출·외부 손실을 합산했습니다. 식물 흡수와 고사물은 내부 전송으로 처리하고, 아직 식물 재고에 포함된 곡실 N을 수확 반출로 다시 더하지 않았습니다. 잔차 0.000034343kg N/ha는 출력·네이티브 반올림 한도 0.0950732 이내입니다. 이 결과는 해당 1시즌의 **물리적 수확 반출 전** 재고 검사이며 수확 후/전체 C 검증 게이트는 유지합니다.
