# Fang2014 계보 추적과 독립성 근거 검사

완료일2026-11-07(한국 시간, 시작11월6일). Fang2014의 서지·공식 요약은 확인했으나 원문 장의 계수표와 정확한 패키지 계보는 확보하지 못했다. LIRF의 독립 검증 자격은 미확정으로 유지하고, 준비상태 보고서에 근거가 고정된 계보 검사를 연결했다.

## 공개자료 확인 범위

대상 장은 DOI `10.2134/advagricsystmodel5.c1`이다. [USDA 공식 기록308258](https://www.ars.usda.gov/research/publications/publication/?seqNo115=308258)은2008–2011년 여러 관수 처리로 RZWQM2를 보정했다고 설명한다. 정확한 계수·최적화 후보·선택 이력·동결 시점은 요약만으로 확인하지 못했다.

출판사 페이지는HTTP403, 확인한 RZWQM 출판 목록 PDF URL은HTTP404였다. 다른 공개 경로인 공식 NAL Handle은HTTP200으로 도서관 카탈로그 HTML에 연결됐으며 PDF 원문을 제공하는 응답은 아니었다. 접근 제한을 우회하지 않았다. 이를 원문이 어디에도 없다는 결론으로 일반화하지 않는다.

두 열 모두6개 중3개만 패키지와 정확히 같으며, 일치하는 계수의 종류도 다르다. 여러 열에서 맞는 값만 조합해 정확한 계보라고 부르지 않는다. 이 논문의 같은 현장2012/2013/2015년 자료는 추가 독립 연구로 등록하지 않았다. 후년의0–200cm 반복 간50mm 오차 설명도2008년 상부105/135cm의 일별 오차 기준으로 옮기지 않는다.

Fang2014 장의 계수 벡터는 null로 보존했다. 정확한 보정노출이 알려지지 않은 패키지에 대해 ‘독립 검증 가능’ 또는 ‘특정 절차로 보정됨’을 단정하지 않는다. 이전 입력·품종·측정 불확실성 제한도 그대로 유지한다.

## 실행 가능한 계보 검사

`src/mars_env/validation_lineage.py`의 `independent_lineage_status`를 `scripts/build_readiness_report.py`에 연결했다. 독립 검증 예정 연구에 대해 다음 조건을 확인한다.

- 레지스트리의 정확한 계보·보정 독립성·독립 검증 허용 플래그가 JSON boolean true여야 한다.
- 근거 경로가 작업 폴더 안에 있어야 하고 고정 SHA256과 파일 바이트가 같아야 한다.
- 근거의 연구 식별자가 일치하며, 실행 통과·정확 패키지 계보 확인·전체 연구 독립성 확인이 각각 true여야 한다.

한 조건이라도 부족하면 계보 자격을 거부하고 사유를 남긴다. 레지스트리 표시만 true로 바꿔도 부정 판정을 덮어쓸 수 없다. 양성 시험용 fixture의 계보 자격 통과도 전체 연구/본학습 준비 완료를 뜻하지 않는다. 실제 LIRF는 고정된 부정 근거와 미확정 플래그로 거부된다.

새 검사는 표시만으로 승격, 부정 근거 덮어쓰기, 파일 변조·연구 불일치·폴더 밖 경로·잘못된 JSON, 양성 근거의 제한된 범위를 검증한다. 최초 테스트는 시스템 임시폴더 권한 때문에 오류가 나서 기존 검사와 같은 작업 폴더 `tmp`로 격리해 해결했다. 원본 자료나 모형 오류와 구분했다.
