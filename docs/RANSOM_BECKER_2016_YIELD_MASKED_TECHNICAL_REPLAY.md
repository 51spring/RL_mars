# Becker 2016 관측 수량을 가린 64시험구 기술 재현

2026-11-08 한국 시간. 시험구 64개마다 Hubbard·Mosford 토양 후보와 P0157AMX 수동·자동 계수 두 세트를 모두 실행하도록 256조건을 사전 고정했다. 두 토양에 초기 배수상한을 공통으로 적용했고, 관측 코어 오차나 관측 수량을 사용한 선택은 없었다. 나머지 입력은 이전 단계의 공통 가정과 관리 기록을 사용했다. 범용 생태형 IB0001, 파종 깊이 5 cm, 관수수 질소 표층 배치와 비질소 양분 생략은 기술 조건으로 남겼다. 사전 점검 항목은 네이티브 종료, 일별 기상 및 관수·질소량, 내부 파일의 토양 ID·품종 계수·파종 입력, 출아·75% 출사·생리적 성숙·수확 순서, 일별 생육·식물 질소 출력의 날짜 연속성이다. 관리 일지의 10월 14일을 수확일로 지정했다. 시뮬레이션 수량 원본은 후속 비교용으로 해시만 기록했고, 이 단계에서 관측 수량 파일은 읽지 않았다.

첫 실행에서 기상 파일을 이미지의 공용 디렉터리에만 둔 결과 256건이 DSSAT 오류 코드 29로 종료됐다. 오류 상황에서도 완료 플래그가 기록됐다. 첫 결과를 보존하고 공용 기상 파일과 동일한 파일을 각 실행 폴더에 배치해 재실행했다. 검산에 오류 경고와 필수 출력 확인을 추가했다.
