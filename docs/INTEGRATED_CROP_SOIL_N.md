# 통합 작물·토양 N 재고 검증

2026-11-06. 이전 v2 후보의 실제 네이티브 출력64조건을 독립 재구성했습니다. 새 시뮬레이션/학습은 실행하지 않았습니다. 검증 범위는 같은 토양·품종의 두 시드, 관리/무투입, 피해 유무, Q/F, 수확률 조건이며 전체 원소 C나 농학 검증은 포함하지 않습니다.

## 수지와 시점

```
잔차 = 토양 유기/무기 N + 서 있는 작물 N
     + 미전송 뿌리 고사 N − 아직 토양에 차감되지 않은 당일 흡수 N
     + 누적 피해/수확/부산물 반출 N + 누적 외부 손실 N
     − 초기 토양 N − 누적 시비 N − 네이티브 출아 초기 N 공급
```

무기화·부동화·흡수·고사물은 내부 전송으로 처리합니다. 누적 낙엽 N을 canopy N에 다시 더하지 않습니다. 수확 전에는 곡실을 포함한 서 있는 식물 재고를 계상하고, 휴경 초기화 이후에는 작물 재고0과 실제 곡실 반출/정의된 부산물 N 배분을 사용합니다. 토양의 HARVRES 유입을 외부 시비로 다시 더하지 않습니다.

실제 SOILNI RATE 코드는 전날 UNO3/UNH4를 토양에서 차감합니다. 따라서 식물에 이미 포함됐지만 아직 토양에서 빠지지 않은 당일 흡수 N을 일별 미정산 전송으로 표시합니다. 당일 흡수는 **네이티브 누적 WTNUP의 일별 차이**로 얻고, 다음 날 토양 RNUP와 대조합니다. 성숙 후 TRNU는 마지막 값이 남을 수 있으므로 일별 흡수로 사용하지 않습니다.

마찬가지로 뿌리 고사물은 발생일에 식물에서 빠지고 다음 날 토양에 들어갑니다. 당일 pending stock과 다음 날 ASENN을 대조합니다. 이 시차를 빼기 전 최대 잔차가 큰 날도 별도 보존하며 잔차에 맞춘 상수/계수는 추정하지 않습니다.

수확일의 마지막 작물 출력과 다음 휴경의 DAS0 출력은 날짜가 같아도 서로 다른 초기화 단계입니다. 두 행을 합치거나 버리지 않고, 토양 재고 증가가 네이티브 HARVRES N과 일치하는지 확인합니다. 이번 자료에서는 마지막 미전송 흡수/뿌리 고사량이0이며, 이 값이0이 아닌 종료 조건은 별도 검증 없이 거부합니다.

## 외부 항목과 정밀도

- 시비는 실제 행동의 정수 투입량을 MgmtEvent와 SoilNiBal AFERT에 대조합니다. 0.0으로 출력된 날마다 ±0.05를 합산해 불필요하게 큰 허용오차를 만들지 않습니다.
- 외부 손실은 용탈·타일 배수·유출·NH3/N2O/N2/NO 방출입니다. 토양 잔류 기체 N은 재고에 남기고 방출만 외부 손실로 셉니다.
- SoilNoBal의 HUMN/FON/RESN과 SoilNiBal의 NO3/NH4/urea/기체 등 재고를 합산합니다. 이번 Q/F의 SoilNBalSum 파일은 비어 있어 사용하지 않았습니다.
- 허용오차는 실제 출력 토큰의 소수 자릿수에 따른 반 단위 오차와 네이티브 binary32 합산 한계에서 계산합니다. 일별 손실을 합산하므로 최종 한계는 약0.147kg N/ha입니다. 이보다 작은 누락이 모두 검출된다는 의미가 아닙니다.

고정/침수 N·외부 유기 잔사 투입이 없는 현재 영역만 지원하며, 발견되면 임의0으로 처리하지 않고 거부합니다. 부산물 N은 계속 측정값이 아닌 v2 배분 정의입니다.
