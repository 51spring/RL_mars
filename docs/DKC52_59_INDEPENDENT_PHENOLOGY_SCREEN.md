# DKC52-59 독립 생육 관측과 CERES-Maize 계수 대조

2026-11-08 한국 시간. KBS033 수량을 사용하지 않고 독립 연구에서 동일 품종의 수치 관측을 찾았다.

- dos Santos 등은 DKC52-59를 2006년 출시·상대숙기 102 품종으로 등록했다. 시험은 잎깃이 보인 잎 수를 반복 관측했고, 50% 출아부터 50% 꽃가루 방출 또는 출사까지의 열시간을 사용했다. 공개 본문과 보충자료 설명에서 품종별 날짜·열시간을 연결할 수 있는 DKC52-59 개별 자료는 확보하지 못했다. 출판사 보충 DOCX는 두 경로에서 HTTP 403이었다. 보충 설명에 나온 숙기군 수준의 잎 출현율을 이 품종의 계수로 옮기지 않았다. [Crop Science 논문](https://doi.org/10.1002/csc2.21044)
- 캔자스주립대 2012년 Table 5의 DKC52-59 행에서 Parsons 천수 시험의 출사 소요일 **71일**을 확인했다. Ottawa 열은 결측이다. 같은 보고서의 지역 기상 페이지에 4월 4일 파종과 8월 1일 수확이 있으나 그 페이지의 표기는 Four-State Farm Show, Pittsburg다. 정확한 포장과 관측소를 연결하기 전에는 71일을 달력 날짜나 적산온도로 환산하지 않는다. Table 9의 GDD 2,540과 DBL 102는 출품자 제공값이다. [캔자스주립대 보고서](https://www.agronomy.k-state.edu/outreach-and-services/crop-performance-tests/documents/corn/corn-2012.pdf)
- 미네소타 Lamberton·Waseca의 2008–2010년 시험에서는 DKC52-59로 파종일 3수준과 최종 밀도 6수준을 비교했다. 출사기 LAI·IPAR, 수량과 낟알 구성 자료가 있어 KBS033의 파종밀도 차이를 검토할 독립 후보다. 해당 공개 요약에서 반복 측정된 잎 출현이나 포장별 출사일 시계열을 확인하지 못했다. [논문](https://doi.org/10.2134/agronj2011.0071) · [학위논문](https://conservancy.umn.edu/bitstreams/b59a8aa1-a098-40f1-93ab-52c9ceca6937/download)

| CERES 계수 | 자료로 확인 가능한 범위 |
|---|---|
| P1·P2 | 출사 71일은 한 시험에서 전체 출사 예측을 비교할 후보다. 단일 시점으로 유년기 열시간과 일장 반응을 각각 추정할 수 없다. |
| PHINT | 잎깃 출현 간격을 CERES 잎끝 출현에 연결하려면 같은 온도 누적법과 단계 관측의 대조가 필요하다. |
| P5 | 출사부터 생리적 성숙까지의 관측이 필요하다. 기계 수확일과 출품자 제공 숙기 값은 분리했다. |
| G2·G3 | 낟알 수 관측은 조건별 반응을 평가할 수 있다. 잠재 최대 낟알 수와 최적 조건의 등숙 속도에는 각각 적합한 조건과 시계열이 필요하다. |

로컬 CERES-Maize 품종 파일에 DKC52-59 항목이 없었다. 독립 계수 확정 0개이며, DSSAT 실행과 정량 검증 등록은 보류했다. 다음은 미네소타 시험의 공개 표와 반복구 자료 범위를 확인해 밀도 효과 및 수량 구성 관측을 어디까지 재현할 수 있는지 판정하는 작업이다. 소프트웨어 검사 204개를 통과했다.
