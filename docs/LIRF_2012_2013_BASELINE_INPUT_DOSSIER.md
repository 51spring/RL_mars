# LIRF 2012–2013 기본 생육·수분 반응 입력 명세

USDA 통합 워크북과 데이터 사전의 원본 해시를 확인했다. 두 해의 12개 관수 처리와 4개 반복구를 `연도·포장` 단위로 확인했고, 물수지표는 `연도·처리·날짜`에 연결했다. 관수·질소·토양수분의 처리 단위 관측을 4개 독립 포장 측정으로 집계하지 않았다. [USDA 자료](https://doi.org/10.15482/USDA.ADC/1439968) · [자료 논문](https://doi.org/10.1016/j.dib.2018.10.140)

| 항목 | 확보한 범위 | 재현에 남은 조건 |
|---|---|---|
| 곡실 수량 | 포장·연도 96개 중 수치 94개. 2013년 D31·C46은 결측이다. 원본 15.5% 수분 수량에 0.845를 곱해 건조 수량을 기록했다. 24개 처리·연도의 유효 n과 표본 SD도 보존했다. | 표본 SD는 포장 간 분산을 기술한다. 블록 대비의 오차를 별도로 계산해야 한다. 2013년 지상부 건물중은 48개 모두 결측이다. |
| 기상 | 시간별 기록 17,543행, 보고 날짜 731일. 시간 끝 기준으로 자정 기록을 전날에 두면 물수지 기간 354일 모두 시간 기록 24개가 있다. | 같은 날짜의 강수가 기상표와 물수지표에서 7일 다르다. 시간별 평균 온도의 극값을 일 최고·최저 실측으로 대입하지 않았다. |
| 관수·질소 | 연속 177일씩 24개 처리·연도, 총 4,248행. 양의 총관수 기록 422행과 명시된 질소 투입 114행의 원본 위치를 보존했다. | 2012년 파종 전 스프링클러 기록은 물수지 기간보다 앞선다. 논문은 관개수 질소를 포함하며, 표의 명시 질소 합계만으로 전체 N을 재현할 수 없다. |
| 초기 토양 | 포장용수량은 24개 처리·연도와 7개 깊이에서 수치 168개다. 일별표에서 일곱 깊이에 수분 수치가 처음 모두 있는 날은 2012-05-25와 2013-05-28이다. | 두 날짜 모두 파종 후다. 파종일 층별 초기 수분과 질산태·암모늄태 N, 나머지 수리 특성 및 포장별 위치 연결이 필요하다. |
| 포장 관리와 품종 | Crop Log에 2012년 4월 30일 시작·5월 1일 B 구역 완료, 2013년 5월 15일 파종이 있다. Comas 논문의 품종 표기는 Dekalb DK 52-04다. | 2012년 물수지표의 공통 파종일과 블록별 작업일을 구분한다. 연말 입모밀도를 파종량으로 쓰지 않는다. 모형 논문의 품종 표기 차이와 정확한 계수 출처를 확인해야 한다. |

2012년과 2013년 완전관수군의 수분 보정 전 평균은 각각 15,733.99와 15,699.40kg/ha로, Comas 논문 표 1의 정수값과 일치했다. 반면 2012년의 일부 HI 값은 동일 행의 건조 곡실·지상부 건물중 비와 차이가 있어 원값을 유지했다. 처리표에 기재된 질소의 연도별 범위는 170–175와 136–147kg N/ha다. 이 값에는 논문이 설명한 관개수의 질소까지 포함한 총량을 부여하지 않았다. [Comas 등, 방법과 표 1](https://doi.org/10.1016/j.agwat.2018.07.015)

Zhang 등의 RZWQM2–CERES 연구는 2012·2013년 완전관수 및 최저관수 처리의 자료가 선행 토양·작물 보정에 쓰였다고 보고한다. 해당 논문의 최종 품종계수에도 별도의 재보정 이력이 있다. 이 계수로 같은 시험을 평가할 때 보정에 사용된 부분을 독립 검증으로 분류할 수 없다. Comas 논문 그림 3에는 별도 정오 차단율 요약이 있지만, 이번 통합 파일 감사에서 포장·시각별 광량 원시값을 확보하지는 않았다. [Zhang 등, §2.2와 표 4–5](https://doi.org/10.1016/j.agwat.2021.106767) · [Comas 등, 그림 3](https://doi.org/10.1016/j.agwat.2018.07.015)

다음은 GLY04와 Crop Log를 사용해 강수 불일치 7일, 처리별 총관수·관개수 N, 파종·수확일의 출처를 대조하는 단계다. 현재 자료는 물 반응을 검토할 후보이며, 기상 입력·품종계수 할당과 농학 정량 검증은 보류 중이다. 검증 결과를 재생성해 해시 일치를 확인했고 소프트웨어 검사 204개가 통과했다.
