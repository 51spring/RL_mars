# 관수 및 관수·시비 PPO 예비 비교

2026-11-09 한국 시간. 무해충 DSSAT에서 관수 전용 PPO와 관수·시비 공동 PPO를 각각 16,384단계 학습했다. 관수 전용 정책은 기존 시비 규칙을 자기 관측과 마스크에 적용한다. 공동 정책은 관수와 시비를 선택한다. 두 정책 모두 살포를 0으로 고정했고 같은 자원 제약을 사용했다. CPU 워커 4개, 정책 시드 42, 같은 학습 단계 수와 기존 희소 투입 초기화·보상 설정을 사용했다. 각 학습에서 시즌 120개가 완료됐고 생육 실패는 없었다. 학습 시간은 각각 114.7초와 117.2초였다. [실행 설정](../outputs/runs/20261109T080153Z_water_nitrogen_ppo_pilot_67bc61f5/design.json)

기준선은 기존 고정 관수·시비 규칙이다. 학습은 train 구간에서 진행했고, 평가는 이전 기준선 비교에서 사용하지 않은 validation 시즌 16–31에서 세 방법을 모두 실행했다. 각 최종 체크포인트는 결정론적 행동으로 평가했다. 평가 수익은 곡실 판매 수익에서 투입비를 뺀 원수익으로 집계했다. 최종 test 구간은 사용하지 않았다.

| 방법 | 평균 순수익 (USD/ha) | 평균 수량 (kg/ha) | 평균 관수 (mm) | 평균 시비 (kg N/ha) | 기준선 대비 순수익 승/패 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 고정 규칙 | 838.18 | 6,987.81 | 120.00 | 105.88 | 기준 |
| 관수 PPO + 고정 시비 | 511.13 | 3,853.38 | 0 | 105.88 | 1/15 |
| 관수·시비 공동 PPO | 185.16 | 1,171.88 | 0 | 0 | 0/16 |

관수 PPO는 기준선보다 평균 327.05 USD/ha, 공동 PPO는 653.03 USD/ha 낮았다. 이 체크포인트의 결정론적 평가에서 두 PPO 모두 관수를 선택하지 않았고, 공동 PPO는 시비도 선택하지 않았다. 생육 실패와 자원 제약 위반은 세 방법 모두 0건이었다. 정책 시드 한 개와 단일 예비 학습 길이에서 얻은 결과다. 첫 실행은 보상 감사 콜백이 종료 때만 제공되는 필드를 일반 단계에서 읽어 중단됐다. 수정 후 두 학습과 평가 48회가 완료됐으나 종료 직후 자식 프로세스 검사에서 중단됐다. 저장한 체크포인트를 재학습 없이 불러 별도 컨테이너에서 평가 48회를 다시 실행했다. 원래 평가와 재평가의 48개 기록 해시가 모두 일치했고, 재평가 종료 후 남은 자식 프로세스는 없었다. 독립 집계에서도 수익과 체크포인트 해시가 일치했다.
