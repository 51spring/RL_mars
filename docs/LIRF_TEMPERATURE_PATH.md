# LIRF 온도 입력 경로와 진단 민감도

2026-11-06. 고정 이미지의 수동 PDI에서 사전 지정한 5조건을 실행했다. WTH 온도 매개변수가 기본 토양온도 계산으로 전달되는 기술 경계를 확인했으며 현장 매개변수는 선택하지 않았다. 연구·본학습 게이트는 false다.

## 소스 경로

고정 소스의 `CMakeLists.txt`는 `Weather/IPWTH_alt.for`를 포함한다. 이 입력기는 WTH station 헤더의 `AMP`를 `TAMP`로 직접 읽으며 배율을 적용하지 않는다. TAV 또는 TAMP가 0 이하이면 각각 20, 5로 대체한다. 따라서 실제 연평균 기온이 0 이하인 지역에는 이 기본값 규칙을 별도 검토해야 한다. 이번 양수 후보의 적용 가능성과는 구분한다.

`Weather/weathr.for`는 TAMP를 WEATHER 구조체에 그대로 넣는다. `InputModule/IPSIM.for`의 기본 METMP는 D이며, `SPAM/SPAM.for`에서 D는 기존 STEMP 경로, E는 EPIC 경로를 선택한다. 원 FileX에 없는 METMP는 D로 처리된다. 이번 진단에서는 D를 명시하고 VBOSE D로 SoilTemp.OUT을 추가했다. MESOL2는 토양층 분할 방법으로 METMP와 다른 스위치다.

기본 `SPAM/STEMP.for`의 TA와 깊이별 계절항은 TAMP/2를 사용한다. 동일한 TAMP를 쓰는 `weathr.for`의 일별 normal temperature TA는 1/2을 적용하지 않는다. EPIC 내부 SOILT_EPIC는 이 계절항과 다른 식을 사용한다. 따라서 모든 사용처에 적용할 단일한 배율 보정으로 해석하면 안 된다.

`Weather/WGEN.for`의 Climate 헤더 파서는 TAV/TAMP를 직접 읽는다. 과거 vol3 문서의 Climate AMP(월평균 최대–최소 차이의 절반)와 현재 코드의 소비처별 사용 차이는 남아 있다. 이번에는 WTH 경로를 실행했고 WGEN Climate 파일 경로는 소스만 확인했다. 역사적 의미의 일관성·WGEN 실행 검증·일반적인 AMP 표준화까지 완료한 것은 아니다.

세부 행 번호·발췌·SHA는 `outputs/runs/20261106T140031Z_lirf_temperature_qualification_9dccaaa6/source_path_audit.json`에 보존했다.

## 사전 지정 조건과 읽힌 값

원 패키지의 2008 단일 처리, Jan1 시작, DATE 헤더 호환, 명시적048 품종6계수를 유지했다. 일별 기상·토양·투입 일정은 바꾸지 않았다. 누락/명시 기본값 회귀와 TAV·AMP의 분리된 진단 대비를 실행 전에 저장했다.

| 조건 | WTH TAV / AMP (°C) | SoilTemp 출력 TAV / TAMP (°C) |
|---|---|---|
| 원 누락값 | -99 / -99 | 20.0 / 5.0 |
| 명시 기본값 | 20.00 / 5.00 | 20.0 / 5.0 |
| 관측기간 평균만 | 8.58 / 5.00 | 8.6 / 5.0 |
| 관측기간 평균·월평균 전체 차이 | 8.58 / 27.16 | 8.6 / 27.2 |
| 관측기간 평균·월평균 차이 절반 | 8.58 / 13.58 | 8.6 / 13.6 |

WTH 후보는 소수2자리, SoilTemp 출력은 F8.1이다. 출력 대조 허용오차0.05001°C는 반올림과 부동소수점 여유이며 농학 정확도 기준이 아니다. 2008–2011년의 공기온도 기술 통계를 토양온도 관측이나 장기 기후 평년값으로 간주하지 않는다.

## 결과와 범위

최종 5회 모두 295일의 단일 시즌으로 완료했고, 기상 5,900항목(SRAD/TMAX/TMIN/RAIN)에 출력 정밀도 밖 불일치가 없었다. 누락값과 명시 기본값의 모든 출력 토양온도 행이 같았다. Summary 및 일별 PlantGro/SoilWat/SoilNi 숫자행도 서로 같고 이전 기본값 실행과 정확히 일치했다.

기본값 대비 TAV만 바꾸면 층별 출력 토양온도의 최대 차이가 7.5°C였고, 고정 TAV에서 전체·절반 진폭 간 최대 차이는 2.4°C였다. 이는 공통 295일·해당 토양/조건에 한정된 기술 민감도다. 표면값은 두 진폭 간 출력 정밀도에서 같았으나 심층값은 달랐다.

다섯 조건의 최종 수확일2008295와 HWAH14668kg/ha는 같았다. 이것으로 토양온도 무영향, 후보값 동등성 또는 현장 수량 적합성을 주장하지 않는다. 원 품종 정체·초기 상태·토양 및 관개수N 등 미확정 항목도 유지한다. 현장 수량과의 오차를 계산하거나 가장 맞는 온도를 고르지 않았다.

## 발견한 입력기 오류와 보존

최초 진단 입력기는 헤더 끝 사이6칸을 모두 수치에 사용했다. `Utilities/READS.for`의 PARSE_HEADERS는 구분 공백을 건너뛰어 다음 필드를 읽으므로 27.161과13.580이 각각7.2와3.6으로 출력됐다. 완료 여부만으로 수용하지 않고 두 후보 조건을 거부했다. 최초 출력은 `outputs/runs/20261106T135757Z_lirf_temperature_f5ce8696`, 거부 근거는 `outputs/runs/20261106T140004Z_lirf_temperature_readback_rejected_51564462/verification.json`에 남겼다.

수정 입력기는 구분 공백을 보존하고5칸 안에 소수2자리로 기록한다. 회귀 검사에 구분 열·실제 필드 폭을 포함했다. native/Fortran/기본 실행 프로필 변경은 없다.

최종 실행: `outputs/runs/20261106T140011Z_lirf_temperature_1d320bb0/verification.json`.
독립 출력 감사: `outputs/runs/20261106T140031Z_lirf_temperature_qualification_9dccaaa6/verification.json`.
