## 새 계약의 선택

수확 보고는 YIELD/GNUP에 EARS를, 서 있는 식물 재고는 PLTPOP를 사용합니다. 생육이나 경제적 수확 보고를 변경하는 대신 수확 경계에서 다음 계약을 명시했습니다.

```
잠재 곡실 반출 = 실제 네이티브 YIELD/GNUP
곡실 반출 = 잠재 곡실 반출 × 곡실 수확률
부산물 후보 재고 = 서 있는 지상부 재고 − 실제 잠재 곡실 반출
부산물 반출 = 부산물 후보 재고 × 줄기 수확률
잔사 = 반출되지 않은 지상부 + 기존 낙엽 건물중 + 뿌리/미전송 뿌리 고사물
```

N에서 낙엽은 canopy N에 이미 포함되어 추가하지 않습니다. 부산물 N은 **실제 잠재 곡실 N을 뺀 나머지를 수확률로 배분하는 정의**이며 별도 측정값이 아닙니다. 이전 v1의 PLTPOP 기준 곡실 N 차감과 구분합니다. 따라서 v1의 적용 여부 판정을 v2의 통과로 덮어쓰지 않습니다.

HRes_Ceres에 넘기는 지역 변수만 변환합니다. GRNWT 입력은 YIELD/(10×PLTPOP), PODWT 입력은 TOPWT−STOVWT×PLTPOP, WTNSD 입력은 GNUP/10, STOVN 입력은 (WTNCAN−GNUP/10)/PLTPOP입니다. 원래 식물 상태·다른 소비자·생육/수량 보고와 뿌리 분포는 유지합니다. 지역 SENESCE 복사본은 중복되는 표면 N만 제외합니다. 단위 ×10 후보를 다시 사용하지 않습니다.

이는 서 있는 재고와 실제 보고된 반출을 일치시키는 경계 계약입니다. 이삭이 없는 식물의 N/건물중을 어느 반출 범주로 분류할지는 농학적으로 추가 검증해야 합니다. 관측되지 않은 부산물 N이나 원소 C를 검증한 것으로 간주하지 않습니다.
