## 관수량은 일치, 날짜 자격은 미완료

일자가 있는 행만 합산해 SUM꼬리표를 중복 계산하지 않았다.1mm/ha=10m3/ha를 적용하면 네 연도×방법의 합계는 수확 시트 적용량과 일치했다. 빈 관수량을0으로 채우거나 전체 일별 무관수 일정으로 확정하지 않았다.
