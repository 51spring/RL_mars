`PAR_by_year`에는 유전자형 ID 369개가 있다. 2019년은 시점마다 수치 309개와 `NA` 60개, 2020년은 시점마다 수치 315개와 `NA` 54개다. 논문의 혼합모형 설명과 대조한 결과 이 열은 유전자형 효과이며 음수도 포함한다. S2는 검정과 집단 요약, S4는 눈에 보이는 잎 수의 비교 결과다. 잎 수와 잎 방향으로 녹색 LAI를 복원할 수 없다.

논문은 군락 위 센서 두 개와 지면 부근 센서 한 개로 PAR를 측정하고, 입사광 대비 투과광 차이로 차단율을 계산했다. 2019·2020년 관측은 조사일마다 10:45~13:00에 이루어졌으며, 표의 DAP는 여러 달력 날짜의 관측을 묶은 명목 시점이다. 보충자료에서 해당 포장의 달력 날짜, 센서별 PPFD 원값, 독립 녹색 LAI가 함께 담긴 관측 행을 확보하지 못했다. 정오 관측 설계는 일조 시간 전체의 적분 자료를 제공하지 않는다.
