# DSSAT 공통 시즌의 해충 민감도 전달 검사

검증 split 시즌 0·1에서 기준, 조사 잡음 0.10, 잎 피해 계수 α 두 배, 살포 효능 0의 네 설정을 실행했다. 시즌 내 DSSAT 시드와 유입·조사 난수를 공유했다. 각 실행의 고정 행동은 관수 40mm, 질소 116kg/ha, 살포 2회였다. 실제 행동 마스크에서 총 1,008일의 고정 행동이 허용됐고, 8회 모두 실제 수확으로 종료됐다.

- 조사 잡음 0.01→0.10에서 공개 조사값은 달라졌다. 같은 시즌의 해충 진단, 잎 상태와 식물체 재고, 조사 외 정책 입력, 수확량·순수익은 정확히 일치했다.
- α를 0.03→0.06으로 바꿔도 해충압은 일치했다. 요청 피해율이 두 배로 증가했고, 실제 잎 상태에 더 큰 피해율이 쓰인 날을 두 시즌에서 확인했다.
- 살포 효능을 0으로 두고 살포 행동과 비용을 맞췄다. 잠재 해충압은 기준보다 낮아진 날이 없었다. 두 시즌 모두 압력이 높아진 날이 있었고, 관측일별 변화는 유입 및 살포 시점의 영향을 받는다.
- 실제로 양의 피해율을 쓴 632일에서 네이티브 잎 건물중·녹색 면적·반출 항등식을 확인했다. 완료일·기온, 일별 계산 재현, 다음 조사 관측의 315차원 정책 입력 계약도 확인했다.

| 검증 시즌 | 실행당 의사결정일 | 기준 평균 적용 피해율 | α 두 배 평균 적용 피해율 | 효능 0 평균 적용 피해율 |
|---|---:|---:|---:|---:|
| 0 | 129 | 0.6994% | 1.3989% | 0.6999% |
| 1 | 123 | 0.7718% | 1.5435% | 1.9359% |

평균 적용 피해율의 분모는 각 실행의 모든 의사결정일이다. 이 수치는 선택한 두 시즌과 고정 행동에서 실제 상태 전달을 확인한 결과다. 포장 피해·회복 보정과 정책 비교에는 별도 실험이 필요하다.

`scripts/verify_faw_dssat_pairing.ps1`로 기존 `mars-dssat:ppo-cpu-metadata` 이미지를 실행한다. 시드, 이미지 식별자, 일별 로그와 결과는 `outputs/runs/20261107T033439Z_faw_dssat_pairing_100018ed`에 있다. Docker 시작 실패는 오류가 난 두 IPC 소켓 폴더를 백업 이름으로 보존한 뒤 재시작해 복구했다. 첫 진단의 직접 import 실패는 기존 Gym/PDI 워커를 사용해 해결했다. 세부 내역은 같은 실행 폴더의 `runtime_recovery.json`에 있다.

다음은 공통 고정 행동에서 보상 계수 η가 단계별 보상 신호와 시즌 누적 원수익에 어떻게 반영되는지 검증하는 단계다.
