# Becker 2016 4블록 탄소·질소 관측 범위와 CENTURY 초기화

2026-11-08 한국 시간. 4블록의 코어 18개 층에 유기탄소와 총질소가 함께 기록돼 있다. 관측 TOC/총질소 질량비는 2.22–14.86이다. 이 비율에는 무기질소가 포함돼 있으므로, 아래의 네이티브 유기 C:N 허용 범위와 직접 비교하는 데 사용하지 않았다. 코어 채취는 4월 26일이며, 비교에 사용한 모의 시작일은 4월 21일이다. [Dryad 원자료](https://doi.org/10.5061/dryad.66t1g1k2g) · [고정 입력](../outputs/runs/20261108T140239Z_ransom_becker_2016_four_block_joint_cn_support_5d774a3d/frozen.json)

4블록×2개 대표 토양에서 기존 기준, 코어가 완전히 덮는 층만 총질소 입력, 최하 코어층의 총질소 심층 연장, 최하 코어층의 유기탄소·총질소 동시 연장을 각각 실행했다. 총질소 입력을 무기질소 차감 후의 유기질소 요청량으로 읽어, 동일 층의 CENTURY C:N 허용 재고와 비교했다. 기준 8개에서 기존 일별 토양 질소·유기물 수지·식물 질소 출력이 재현됐다. 코어가 완전히 덮는 모형층 68개 중 24개가 범위 안에 들었다. 29개는 모델 최소 유기질소보다 낮고 15개는 최대보다 높았다. 별도로 코어가 일부만 덮는 층 8개와 전혀 덮지 않는 층 8개를 표시했다. 미관측 부분을 포함한 층 전체에는 관측 자격을 부여하지 않았다.

총질소를 입력한 24개 조건 모두에서 CENTURY가 전체 프로필의 초기 유기질소를 기본값으로 대체했다. 심층 결측을 연장한 조건에서도 적어도 한 층의 요청량이 허용 범위를 벗어났다. 해당 C:N 조정 경고 문구는 출력되지 않았으며, 네이티브 대체 플래그와 초기 재고를 확인해 판정했다. 4월 21일 현장 초기화와 정량 등록은 미확정이다.

다음은 허용 범위에 들어온 코어 층만 살리고 나머지 층에는 출처가 표시된 기본값을 쓰는 **층별 초기화 대조**다. 초기 C·N 재고와 기존 전층 대체 경로를 함께 검산한 뒤 기술 비교에 한해 사용 여부를 판단한다. 소프트웨어 검사 204개가 통과했다.
