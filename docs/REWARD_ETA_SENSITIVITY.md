# 공통 DSSAT 시즌의 보상 계수 η 민감도

이전 실제 DSSAT 기준 궤적의 고정 행동과 같은 외생 시드를 재사용했다. 기존 η=0.45를 기준으로 0, 0.225, 0.45, 0.90의 상수 프로필을 비교했다. 공통 두 시즌에서 수확까지 8회, 시즌 0에서 의사결정 60일 제한까지 4회, 총 12회를 실행했다. 실제 마스크에서 모든 행동을 확인했고, η 간에는 동일 궤적의 315차원 정책 관측 해시가 일치했다.

| 실행 조건 | 전체 η에서 원수익 또는 중단까지의 원보상 합계 (USD/ha) | η=0.45 비종료 평균 일별 보상 보정의 절댓값 (USD/ha) | η=0.90 |
|---|---:|---:|---:|
| 검증 시즌 0 수확 | 727.072 | 6.327 | 12.653 |
| 검증 시즌 1 수확 | 434.772 | 4.493 | 8.986 |
| 검증 시즌 0 60일 제한 | −214.980 | 3.744 | 7.487 |

모든 단계에서 관측으로 독립 계산한 잠재함수 변화와 반환된 학습 보상을 대조했다. γ=1, 스케일 1,000에서 수확은 최종 잠재함수를 0으로 두었다. 이번 궤적의 시작 잠재함수도 0이어서 수확까지 학습 보상 합계는 네 η에서 원수익/1,000과 일치했다. 망원합 오차의 최대 절댓값은 약 2.27×10⁻¹³이었다.

60일 제한에서 원보상 합계는 −214.980 USD/ha였다. η=0.45의 마지막 관측 잠재함수 224.614 USD/ha를 유지하므로 스케일 적용 후 학습 보상 합계는 +0.009634였다. 이 중단 구간의 보상 합계에는 미정산 잠재함수가 포함된다. 수확수익이나 에피소드 수확 결과는 반환되지 않았다.

이 결과는 고정 행동의 보상 전달과 경계를 확인한 것이다. 실제 PPO 학습 성능이나 계수 선택의 근거로 사용하려면 별도 평가가 필요하다. 본 설정의 η=0.45는 초기 가정이며 본 학습은 보류 중이다. 다음은 같은 실제 롤아웃에서 GAE λ=0.95·0.98의 신호와 종료·시간제한 처리를 기술적으로 대조하는 단계다.
