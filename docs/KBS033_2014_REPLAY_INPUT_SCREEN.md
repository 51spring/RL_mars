2014년은 기상과 농작업 이력이 연결된 재현 후보로 유지한다. 다음은 독립 생육 연구의 보충자료에서 DKC52-59의 잎 출현·개화 관측을 개별 품종 단위로 확인하고, CERES에서 제약할 수 있는 항목을 구분하는 작업이다. KBS 수량을 품종계수 보정에 사용하지 않았다. 초기 토양과 독립 계수가 미확보되어 DSSAT 재현 실행과 정량 등록은 보류했다. 소프트웨어 검사 204개가 통과했다.
