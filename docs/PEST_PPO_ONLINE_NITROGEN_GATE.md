# 공동 PPO의 45일차 이전 시비 제한

고정 관리 규칙과 비교하면 시비 제한은 평균 +2.65 USD/ha였지만 16개 시즌 중 4개에서 앞섰고 하위 10% 평균은 6.55 USD/ha 낮았다. 시드·시즌을 쌍체 재표집한 95% 구간은 기존 공동 PPO 대비 +11.24~+195.77 USD/ha, 고정 관리 대비 −17.83~+33.16 USD/ha였다. 행동 반복을 먼저 평균했으며 하위 10% 평균은 각 시드·반복에서 산출한 뒤 평균했다. 고정 관리는 비교 기준으로 유지한다.
