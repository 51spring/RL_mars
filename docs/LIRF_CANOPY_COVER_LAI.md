# LIRF 군락 피복률과 LAI 원자료 연결

USDA-ARS Colorado LIRF의 2012~2013년 원본에서 `LAI by Plot`의 LAI와 `Canopy Cover by Plot`의 수직 하향 사진 기반 피복률을 포장·달력 날짜로 연결했다. 날짜와 DOY가 맞는지 검사했고, 연결 키에서 처리 코드와 처리명이 일치했다. 각 셀의 원본 행 번호를 보존했다. [USDA 2012~2013년 데이터](https://catalog.data.gov/dataset/usda-ars-colorado-maize-water-productivity-dataset-2012-2013)

| 조사일 | 같은 포장·같은 날의 두 수치가 있는 행 |
|---|---:|
| 2012-06-14 | 48 |
| 2012-08-16 | 48 |
| 2013-08-15 | 43 |
| 2013-09-04 | 41 |
| 합계 | 180 |

LAI 원본 384행에서 180행을 연결했다. LAI 결측은 14행, 수치형 LAI가 있으나 피복 조사일이 없는 경우는 187행, 같은 키에 피복값이 결측인 경우는 3행이었다. 피복률 원본 1,680행 중 1,624행이 수치다. 2013년 8월 2일 D36과 8월 22일 D21·C31에는 중복 키가 있었다. 해당 날짜는 LAI 조사일과 겹치지 않았다. 중복 키를 전부 제외하고 원본 행 번호를 검증 파일에 남겼다.

연결 범위는 LAI 0.381~5.438, 피복률 10.24~86.05%다. 각 연도 48개 포장이며 한 포장이 여러 날짜에 나타난다. 피복률은 원본 퍼센트와 100으로 나눈 비율을 함께 저장했다. 스케일은 처리 평균과 일별 물수지 시트의 분율을 보조 대조했다. 예를 들어 2012년 6월 14일 처리 1은 원본 처리 평균 16.516525와 일별 분율 0.17이다. 물수지 시트에는 보간·조정된 처리값도 있으므로 연결에 사용하지 않았다.

2008~2011년 `Tmnt1`~`Tmnt6`의 일별 처리 요약에는 수치형 LAI가 연도순으로 0·19·48·6행 있었다. 주황색 피복 실측 표시와 날짜가 겹치는 2009년 11행과 2010년 12행은 처리 단위로만 연결된다. 2011년 6행은 원본 주석에서 날짜 미상으로 표시한 DOY 220 추정치다. 이 자료에서 포장·날짜 연결 쌍은 확보하지 못했다. [USDA 2008~2011년 데이터](https://catalog.data.gov/dataset/usda-ars-colorado-maize-water-productivity-dataset-2008-2011)

사진 기반 피복률은 지면을 가린 면적 비율이다. 이 연결 자료에는 입사·투과 PAR 및 두 관측의 실제 시각이 없어 CERES 일별 광 차단율과 정량 비교할 수 없다. 다음 진단은 2012년을 개발용, 2013년을 보류 평가용으로 고정해 피복률–LAI 관계의 연도 간 재현성을 확인한다. 같은 시험장의 포장 반복과 조사일 4개라는 범위를 함께 보고한다.
