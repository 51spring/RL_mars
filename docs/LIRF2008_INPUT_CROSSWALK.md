# LIRF2008 토양·초기상태·관리 대응 감사

2026-11-06. 공개 ACE/DOME와 현장 원자료를 대조했다. 새 DSSAT 실행·계수 적합·FileX 자동 변환은 수행하지 않았다. 데이터 불일치를 발견하고 기록한 감사의 통과와 농학 검증 통과를 구분한다.

## 단위 근거

[공식 ICASA 사전](https://github.com/DSSAT/ICASA-Dictionary)을 커밋 `2168f366b7c35ce6997c8fb0055dc259e9341ad3`으로 고정해 CSV12개를 보존했다. 현재 사전은 층 깊이cm, 용적밀도g/cm³, ICNO3/ICNH4는 건조 토양 기준 원소N ppm, FEAMN은kgN/ha, 입도는중량%, SLFC1은cm³/cm³로 정의한다. 현재 정의가2015년 패키지 생성기의 단위 규칙을 증명하는 것은 아니다. PLDP는mm 정의에 `mm or cm !!!` 주석도 있어,50을 그대로DSSAT의cm로 옮기지 않는다.

관리 코드는 FE001=질산암모늄, FE005=요소, IR004=스프링클러, IR005=점적이다. 패키지의 같은 날짜 FE001/FE005는 각각 원소N 양을 갖는 두 이벤트로 합산했다. 이를 원본 UAN 투입과 화학적으로 동등하다고 승인하거나 한 이벤트를 중복으로 삭제하지 않았다.

현장 Tmnt1 점적438.1mm에 강수열에 포함된 스프링클러21mm를 분리하면 총관수459.1mm로 패키지와 일치한다. 원본 기록은 수정하지 않았다.

처리표가 있는5/10–10/23의 강수도 대조했다.21mm 스프링클러를 뺀 현장 강수229.886mm에 비해 패키지 기상 강수는270mm로 **40.114mm 차이**가 남는다. 따라서 총관수만 같다고 전체 물 입력을 재현한 것으로 판정하지 않는다.

패키지 전체 시비는134.4kgN/ha다. 현장 초기N 기록일 이후만 같은 기간으로 비교하면 패키지84.0 대 처리표89.7kgN/ha다.5/10의148kgN/ha는 초기 토양 질산태N이므로 시비에 더하지 않는다.5/10을 초기일로 삼는 실행에서 그 이전4/28 시비를 다시 투입하면 중복될 수 있다.1/1 시작과5/10 시작의 초기조건을 혼합하지 않는다.

## 토양·초기상태

패키지 토양은9층, 초기조건은7층이다. 같은 깊이 경계를 강요하지 않고 겹치는 구간별로 밀도를 적용해 계산했다. 단위가 현재 사전과 같다는 조건에서 원소N 재고는 `ppm × bulk(g/cm³) × depth(cm) ×0.1`, 물 저장량은 `theta × depth(cm) ×10`이다.

- 2008-01-01 패키지0–200cm: 물337.4mm, NO3-N20.553696·NH4-N3.1296, 합23.683296kgN/ha.
- 같은 패키지0–60cm: NO3-N9.381696·NH4-N0.8952kgN/ha.
- 현장 최초 토양N 기록은5/10, 최초 처리표 수분 관측은6/10이다. 다른 날짜의 값을 직접 빼서 초기조건 오차로 판정하지 않는다.

현재 정의와 대조한 문제10건을 보존했다.120cm의 `SLFC1=204836`은 용적 수분함량 범위를 벗어난다. 옆의SLDUL0.204836을 보고 자동으로 소수점을 고치지 않았다.9층 모두 clay+silt+sand 합이1이라 백분율 정의와 맞지 않는다. 분율처럼 보인다고 자동으로100배 하지 않았다. 현재LL/DUL/SAT의 순서는 성립하지만 이것이 전체 프로필 검증을 의미하지 않는다.

현장 토양 파일은16개 표본 위치의 지평별 자료와 여러 해를 묶은 밀도·수분 자료를 포함한다. 패키지의 `nunn` 프로필을 특정 위치/2008 T1 포장과 연결하는 검증된 대응은 아직 없다. 연도 간 평균을2008년의 개별 포장 실측으로 표시하지 않는다.
