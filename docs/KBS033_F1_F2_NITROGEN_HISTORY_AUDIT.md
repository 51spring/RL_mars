# KBS033 F1·F2 포장과 기비·추비 이력

2026-11-08 한국 시간. 시험지 D 수량표와 농작업 일지를 대조했다. F1과 F2는 수량표에 기록된 모든 시험지 D 연도에서 각각 동일한 8개 포장을 유지했다. 2005·2008·2011·2014·2017년 옥수수 수량표는 F1/F2를 0/34 kg/ha로 기록한다. 2011·2014·2017·2020·2023년 추비 일지의 F1/F2는 모두 0/0 lb N/ac이며 각 해에 두 처리의 16개 포장 키가 일치했다. [수량표](https://lter.kbs.msu.edu/datatables/77) · [농작업 일지](https://lter.kbs.msu.edu/datatables/299)

| 시즌 | 파종 기비의 근거와 범위 |
|---|---|
| 2005 | 수량표의 처리량을 확인했다. 파종일 포장별 기비 실적은 미확인이다. |
| 2008 | 파종 기록은 천수·관수의 F1 전 반복에서 비료를 제외했다고 명시한다. |
| 2011 | 기비 제외 목록 8개 중 7개가 F1 포장과 일치한다. 일지의 230과 수량·추비 기록의 203은 원문 그대로 두었다. |
| 2014 | 기비 제외 목록 8개가 F1과 모두 일치한다. 기비는 19-17-0이다. 천수와 관수의 파종량은 각각 30,000·39,000 seeds/ac였다. |
| 2017·2020 | 파종 기록에 기비 투입이 있으나 F1 제외 여부는 해당 기록에서 확인되지 않았다. |
| 2023 | 6월 20일 시비표의 파종 기비 계획은 F1/F2가 0/30 lb N/ac이며, 추비는 둘 다 0이다. 일반 파종 기록은 30.25 lb N/ac를 제시하지만 F1 예외를 따로 명시하지 않는다. |

[파종·추비 일지 모음](https://lter.kbs.msu.edu/datatables/299) · [2023년 시비표 첨부 페이지](https://aglog.kbs.msu.edu/observations/5921)

2023년 한 페이지 스캔을 육안으로 판독했다. 9개 처리의 남은 질소량이 같은 날짜의 추비 일지와 일치한다. 시비표 기준 F2−F1의 계절 목표 차이는 33.63 kg N/ha이고 모두 기비 계획 차이다. F9−F1의 추비 차이는 302.63 kg N/ha, 계절 목표 차이는 336.26 kg N/ha다. 이전 결과에서 2023년의 기비를 공통으로 적은 부분을 정정했다. 목표량과 포장별 실제 토출량은 구분하고, 인·황·아연도 포함된 기비와 고정 포장 이력 때문에 F2−F1 수량 차이를 질소 단독 효과로 해석하지 않았다.

2023년 F2를 기준으로 F9와 비교하면 4쌍씩에서 천수 +7.23 t/ha, 관수 +8.54 t/ha다. 시비표상 두 처리의 기비 계획은 같고 추비만 다르지만, 포장별 과거 투입과 토양 초기 상태는 여전히 미확인이다. 다음에는 F1 기비 제외가 명시된 2014년의 관수·기상·파종밀도·토양 입력을 대조해 DSSAT 재현 후보 범위를 정한다. 정량 검증 승격은 0건이다.
