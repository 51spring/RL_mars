# Plano 2016 무시비 DSSAT 네이티브 기술 대조

고정한 16개 조건을 기존 격리 DSSAT 이미지에서 모두 실행했다. 4월 13일부터 6월 13일까지 992개 조건–일을 검산했다. 일별 수분과 무기질소 출력이 모든 조건에서 200 cm까지 이어졌고, 네이티브 입력에서 P0157AMX 자동 보정 계수 6개와 기술용 생태형 IB0001을 확인했다. 수량값은 평가에 사용하지 않았다. [고정 설계](RANSOM_WISCONSIN_PLANO_2016_DATED_INITIALIZATION_TECHNICAL_PROBE_DESIGN.md)

## 초기 재고와 장부

초기 수분은 입력과 일치했다. 무기질소는 DSSAT 내부 파일의 층별 농도와 용적밀도로 재계산한 초기 재고와 장부가 출력 정밀도 안에서 일치했다. FileX에서 내부 입력으로 변환할 때 생긴 성분별 재고 차이의 최대 절댓값은 0.063808 kg N/ha다. 6월 13일까지 관수와 처리 시비가 0임을 확인했다.

| 최대 절댓값 | 물 mm | 무기질소 kg N/ha |
|---|---:|---:|
| 네이티브 누적 잔차 | 0.01 | 0.0000 |
| 출력으로 독립 재계산한 누적 잔차 | 0.09 | 0.0027 |

Lake Geneva 관측소의 NOAA 월평년 기온을 이용해 기술용 TAV 9.66°C, AMP 14.36°C를 적용했다. 일별 기상은 Ransom 시험 자료를 사용했다. 알베도 0.13, 유출곡선번호 60, 뿌리성장계수 1은 이전 기술 설정에서 가져왔다.
