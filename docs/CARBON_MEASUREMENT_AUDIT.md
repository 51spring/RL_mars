## 토양 출력 검사

각 네이티브 RUN을 분리해 다음 식으로 DAYBAL을 독립 재구성했습니다.

```text
오늘 최종 SOM/FOM/CH4 C − 오늘 출력의 초기 SOM/FOM/CH4 C
− 외부 유기물 C − 전날 고사물 C − 첫날 수확 잔사 C
+ CO2ED + CH4ED + CH4LCD + CH4COD
```

고사물은 전날 값을 사용하고 새 RUN에서는 지연값과 누적값을 초기화합니다. 같은 날짜가 다른 초기화 단계에 나타나도 합치거나 버리지 않습니다. CUMBAL의 일별 차이와 DAYBAL도 대조합니다. 첫 휴경 출력의THRC0D/THRC1D는 고정밀 토양 전달 기록의 표면/뿌리 건물중×0.4와 대조하고, 이후 반복 유입은 거부합니다. 이 전달에서0.4는 네이티브 **토양 회계 가정**입니다.

16개 실행·5,696일의 출력 계산 및16건의 잔사 전달 검사가 통과했습니다. DAYBAL 재구성 최대 오차0.027400kg C/ha, 항별 출력 반올림에서 계산한 최대 한계0.100050kg C/ha입니다. 이는 물리적 수지의 허용오차나 모형 오차 보정값이 아닙니다. **후속 다년 검사에서 최종 휴경9일씩 출력 버퍼에 남아 있었음을 확인했습니다.** 보고된CUMBAL −0.0436~0.0175kg C/ha는 각RUN의 마지막 출력값 범위이며, 최종 휴경에 대해서는 실제 종료일 값으로 해석할 수 없습니다. 존재하는5,696일의 산술 검사는 유효하지만 전체 기간/생태계C 보존을 주장하지 않습니다. 제한과 보완은 `MULTIYEAR_RESIDUE_HANDOFF.md` 및 `configs/evidence_qualifications.json`에 기록했습니다.
