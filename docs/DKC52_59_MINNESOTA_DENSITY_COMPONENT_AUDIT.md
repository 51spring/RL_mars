# 미네소타 DKC52-59 재식밀도와 수량 구성 감사

2026-11-08 한국 시간. Van Roekel의 학위논문 2장 표 7·8을 대조해 밀도 6수준의 관측 평균을 추출했다. 회귀 예측값은 관측에서 분리했다. 시험은 Lamberton·Waseca의 2008–2010년 6개 지점–연도에서 실시했다. 각 지점–연도에 무작위 블록 4개, 주구 파종일 3수준, 세구 최종밀도 6수준이 있어 설계상 세구는 432개다. 공개 포장별 결과 행은 확인되지 않았다. 80,100→107,900 개체/ha에서 LAI는 0.86, 차단 PAR은 1.5%p, 면적당 낟알 수는 290개/m² 증가했다. 낟알 무게는 11 mg 감소했고, 수량 평균은 0.2 Mg/ha 증가했다. 이 차이는 공개 평균의 산술 대비다. 수량은 기계 수확과 손수확 표본을 합성했고 낟알 구성은 이삭 부분 표본에서 얻었다. 평균 낟알 무게와 평균 낟알 수를 곱한 값을 포장 수량 수지로 쓰지 않는다. 낟알 수와 최종 밀도의 평균 비율도 CERES G2의 잠재 최대치가 아니며, 단일 최종 무게로 G3 등숙 속도를 구할 수 없다.

LAI와 IPAR는 같은 LP-80을 사용해 맑고 잔잔한 날 11:30–14:30에 측정했다. 조사 시점은 가장 늦게 파종한 처리의 출사에 맞췄다. 따라서 두 값은 같은 밀도에서의 동시 관측 평균으로 남기고, 모든 처리의 출사일 관측이나 일 적산 광 차단량으로 취급하지 않는다.

KBS033 2014년의 천수·관수 파종량은 각각 약 74,132·96,371 seeds/ha다. 수치상 미네소타의 66,200–80,100·94,000–107,900 개체/ha 사이지만, 미네소타는 V5에 솎아 최종 개체밀도를 맞췄고 질소 157 kg N/ha를 파종 전에 공통 투입했다. KBS에는 실측 최종 개체밀도와 이에 대응하는 수분·질소 조건이 없다. 미네소타 곡선으로 KBS 수량을 보정하거나 CERES 계수를 추정하지 않았다.

다음은 KBS033 2014년 포장별 최종 개체밀도 자료의 출처를 확인하는 작업이다. 자료가 연결되는 범위에서만 2014년 재현 후보를 다시 판정한다. 정량 등록 0건이며 소프트웨어 검사 204개가 통과했다.
