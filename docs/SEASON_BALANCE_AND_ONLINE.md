# 시즌 질소 진단과 온라인 해충·조사 연결

현재 범위는 **미보정 계수를 사용하는 실험용 소프트웨어 검증**입니다.
연구용 실행 허용, 농학적 피해/회복 보정, 전체 탄소·토양 수지 검증을 뜻하지 않습니다.

## 누적 제거량과 식물체 질소 수지

Fortran에서 제거 건물중·질소를 시즌별로 누적하고 Python `RemovalLedger`가 일별 제거량을
독립적으로 합산해 대조합니다. 같은 날짜 중복 차감·누적량 누락은 거부합니다.
소스 복사본의 RUNINIT/SEASINIT에서 누적량을 0으로 초기화합니다.

질소 진단식의 모든 항을 kg N/ha로 맞췄습니다:

```
잔차 = 서 있는 지상부 N + 뿌리 N + 누적 뿌리 고사 N + 누적 섭식 제거 N
       − 누적 흡수 N − 종자 초기화 N
```

종자 N은 MZ_GROSUB의 출아 초기화에서 ROOTN·STOVN이 설정되는 바로 그 지점의
(ROOTN+STOVN)×PLTPOP를 별도로 읽습니다. 잔차에서 상수를 추정하거나 결과에 맞춰 보정하지 않습니다.
원본 생육 식과 N 입력/흡수 계산은 바꾸지 않습니다.

`CumLfNSenes`는 고사엽에 배정된 N을 추적하지만 원본 STOVN/WTNCAN에서 독립적으로
차감되는 별도 저장고가 아닙니다. 이를 지상부 N에 다시 더하면 중복 계산입니다.
초기 진단에서 관측된 약 3kg/ha 잔차는 이 중복 합산과 출아 종자 입력 누락 때문이었습니다.
MZ_GROSUB의 출아 초기화·곡실 N 전이, MZ_NUPTAK의 뿌리 고사/흡수 식을 확인하고 진단식을 수정했습니다.

8개 실제 시나리오 모두 허용치 0.001kg N/ha 안에서 식물체 N 재고 수지가 닫혔습니다.
관측된 최대 절대 잔차는 약 0.000051713kg N/ha였습니다.
검증에는 무피해, 86일 연속 3% 피해, 단일 95% 피해, 후기 50% 피해,
온라인 무살포/살포, alpha=0 및 같은 무피해 대조를 포함합니다.

이 결과는 검증된 원본 모형 경로의 식물체 N 재고 수지입니다.
토양 전체 N·원소 탄소·호흡/동화·수확 후 잔사 처리를 모두 닫은 생태계 수지는 아닙니다.
탄소 조직 조성·동화/호흡·종자 건물중 등의 입력/출력이 추가로 필요하므로
`whole_season_carbon_nitrogen_balance`는 False로 유지합니다.

큰 32비트 실수 저장고에서 작은 제거량을 뺄 때 차감 오차가 생깁니다.
국소 수지 검사에는 기존 상대 오차 3e-5와 절대 오차 2e-5 외에,
저장고 크기 및 float32 epsilon=2^-23에 근거한 네이티브 연산 반올림 한계를 사용합니다.
제거량을 0으로 누락하는 경우는 계속 실패하도록 소프트웨어 검사합니다.

## 온라인 연결의 일별 순서

`CSM.for`의 매일 OUTPUT 이후에 `mars_day_finish` 이벤트를 추가했습니다.
출아 전이라 잎 쓰기 이벤트가 없는 날과 종료일에도 작동합니다. 파종 전은 해충 시즌에 포함하지 않습니다.

1. 아침에는 직전 완료일까지 계산된 조사값만 관측으로 제공합니다.
2. 관수·질소와 살포 여부를 전달합니다.
3. 당일 실제 기상을 읽고 생육·질소 흡수를 완료합니다.
4. 말기 잎 쓰기 직전에 당일 Tmin/Tmax 평균으로 해충 밀도·잔효·희망 피해율을 한 번 계산합니다.
5. 실제 녹색 잎이 있을 때만 피해를 쓰고, 없거나 종료된 작물에는 쓰지 않습니다.
6. 하루 종료에서 실제 적용된 손실을 조사 큐에 넣고 다음 아침 조사를 준비합니다.
7. 당일 잎 쓰기가 없었던 출아 전/종료일에도 해충 상태는 한 번 전이하고 실제 손실은 0으로 기록합니다.

같은 날짜의 prepare 재호출은 같은 기상/행동일 때만 허용합니다.
미래 날짜 점프·하루 중복 종료·계산값을 초과한 실제 손실은 거부합니다.
유입과 조사 잡음은 기존 공통 외생 배열의 날짜 인덱스로 읽습니다.
현재 g(T)의 T로 Tmin/Tmax 평균을 쓰는 것은 명시한 실험 가정이며 보정 완료 값이 아닙니다.

## 관측과 환경

`ExperimentalPestEnv`는 별도 실험용 클래스입니다.
`CropManagementEnv(pest_enabled=True)`의 연구용 실행 거부는 유지합니다.
실험 클래스는 매 reset/step info에 experimental_only=True, research_ready=False를 표시합니다.
필요한 시즌·온도 기준·조사 잡음은 생성 시 명시해야 합니다.
기본 설정 파일의 미정 온도/잡음 값을 자동으로 채우지 않습니다.

관측 스키마는 `mars-experimental-pest-v1`, 45필드×7일=315차원입니다.
기존 조사 자리에는 실제 모델 조사값·경과일·가용 여부만 넣습니다.
실제 밀도·내부 진단·미래 유입/잡음은 관측 및 info에 넣지 않습니다.
초기 이력·마스크·자원 원장·raw 수익·실제 수확/실패와 시간제한 계약을 유지합니다.

검증 계수는 온도 기준 10/30°C, 조사 잡음 표준편차 0.01로 명시했습니다.
이 값은 진단 재현용이며 연구의 보정값/현실 권고가 아닙니다.
온라인 3개 조건의 밀도·잔효·희망 피해율·조사는 오프라인 수식 재실행과 일치했습니다.
실제 완료일 기상값을 확인했고, alpha=0의 작물 전체 궤적은 무피해 대조와 정확히 일치했습니다.
별도의 실제 Gymnasium 2개 시즌에서 공개 조사 필드·315차원·마스크·살포 비용·최종 수익을 확인했습니다.
진단 정책의 수익이나 살포 효과를 H1~H3/정책 성능 결과로 해석하지 않습니다.

## 실행 및 근거

```powershell
docker build -f docker/Dockerfile.leaf -t mars-dssat:leaf-experimental .
.\scripts\verify_season_balance_online.ps1
.\scripts\verify_experimental_env.ps1
.\.venv\Scripts\python.exe scripts/run_tests.py
```

- `outputs/season_balance_online_verification.json`: 8개 시즌, 일별 N 항목과 온라인 재실행 결과
- `outputs/experimental_pest_env_verification.json`: 2개 실제 Gymnasium 시즌
- `outputs/core_test_results.json`: 소프트웨어 검사 69개 (현재 전체 검사; 본 단계 당시 63개)
- `outputs/native_leaf_verification.json`: 배포 원본/소스 대조/수정 무피해 회귀
- `outputs/native-leaf-image-id.txt`: 최종 실험 이미지 ID

잠재함수 보상·실제 PPO 연결 후속 진단은 REWARDS_AND_REAL_PPO.md에 기록했습니다. 탄소/토양 수지와 보정 자료는 남아 있습니다.
