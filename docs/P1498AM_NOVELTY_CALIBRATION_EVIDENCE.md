# P1498AM Novelty 외부 보정 자료 감사

Lewis 2015 수량을 검증용으로 보존하고, 미주리 Greenley Research Center의 2013–2015년 Novelty 시험을 별도 보정 자료로 조사했다. Kaur 등의 2018년 식물체 질소 논문과 2020년 수량 논문은 동일 장소·기간·품종·처리와 15개 관리 날짜가 일치한다. 같은 현장 시험의 서로 다른 측정 항목으로 연결했다. 두 원문의 출판사 XML과 PDF를 확보했으며 핵심 표를 PDF 페이지에서 대조했다. [식물체 질소 논문](https://doi.org/10.3390/agronomy8070102) · [곡실·사일리지 논문](https://doi.org/10.3390/agronomy10030378)

## P1498AM 수량에서 확인 가능한 범위

2020년 Table 5는 2015년 P1498AM의 파종 전 질소원 4종 × 구제 시비 2수준 수량 8개를 제공한다. 각각은 무침수·7일 침수를 합한 주변평균이며, 수분 기준은 15%다. 건물로 환산한 범위는 3.56–9.13 Mg/ha다. Table 4는 같은 8개 질소 조합에 대해 침수 기간을 분리하고 두 품종을 합쳤다. 각 질소 조합의 두 표 합계 차이는 최대 0.01 Mg/ha다. [2020년 Table 4–5](https://doi.org/10.3390/agronomy10030378)

침수 2수준 × 품종 2종의 균등 가중 주변평균으로 해석해도, 질소 조합마다 네 수량 중 독립 제약이 세 개뿐이다. 32개 공동 평균에 8개 자유도가 남아 무침수 P1498AM 수량이 유일하게 결정되지 않는다. 예를 들어 완효성 요소·구제 시비 없음에서 두 표의 주변평균을 정확히 만족시키고 공동 평균을 음이 아닌 값으로 제한하면 무침수 P1498AM 수량의 산술 범위는 4.44–17.20 Mg/ha(수분 15%)다. 이 범위는 관측 신뢰구간이 아니다. 공개 표의 유의성 문자로 반복별 오차나 공분산을 재구성하지 않았다.

## 보정 및 재현 자격

미주리대 저장소에 학위논문 정확 제목·저자·관련 키워드 세 검색을 요청했다. 정확 제목 결과는 0개였고, 확인한 검색 응답에서 해당 학위논문 원문을 확보하지 못했다. 저자 소속 대학의 출판 목록에서 2016년 학위논문 기록을 확인했다. 이번 확인 범위에는 품종×침수×질소 공동 수량 원자료와 정확한 P1498AM CERES-Maize 계수·생태형이 없었다. [저자 출판 목록](https://gk478.mufaculty.umsystem.edu/publications)

Novelty는 P1498AM과 침수·질소 반응의 외부 근거로 보존했다. 현재 공개 근거로는 무침수 품종 보정과 Lewis 정량 재현을 보류한다. 검산 JSON을 같은 SHA-256으로 재현했고 소프트웨어 검사 204개를 통과했다.
